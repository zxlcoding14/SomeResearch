# Windows / Mac 高频软件场景全量盘点（细化版）

> 第一层漏斗的完整展开：10 大类、80+ 细分场景。
> 每个场景标注：使用频次（高/中/低）、典型痛点、市场代表产品、小工具适配初判（✔ 强适配 / △ 一般 / ✘ 弱适配），作为进入第二层筛选的输入。
> 初判依据：高频 + 痛点具体 + 单点可闭环 + 桌面端（本地文件/系统集成）有天然优势。

## 盘点小结

- **总量**：10 大类、89 个细分场景，其中"很高/高"频次场景约 45 个，是候选池的主体；
- **初步看,强适配（✔）场景约 20 个**，集中在四类：**文件与文档处理、截图与 OCR、表格数据、会议/音频处理**——共同特征是"本地文件密集 + 操作重复 + 结果质量取决于细节"；
- **弱适配（✘）约 35 个**，淘汰原因集中在：系统/浏览器已内置、免费头部竞品垄断、专业软件领域（IDE/数据库）、平台级赛道（笔记/协作/密码）、合规风险（代理/IM 多开）；
- 本层仅做"全而细"的盘点与初判标注，**正式筛选在第二层进行**（标准：高频 + 痛点明确 + 单点可完成 + 桌面端天然优势），带 ✔ 与部分 △ 场景进入第二层。
