## 统一分析框架

功能与亮点来自榜单标题、标签及帖子热度；用户痛点、需求来源、商业模式为产品经理基于公开信息的假设，须通过访谈、埋点和作者数据验证。收入、用户数、转化率等没有公开披露时不填估算值。

## 榜单信号摘要

1. 高互动集中在“替代昂贵/停止更新产品”（Folo、Listary）和“极致轻量、低打扰”（Catime、PopDrop、SumatraPDF Plus）。
2. 跨平台、开源、本地优先是高频卖点；隐私和可控性是对大厂产品的主要反动。
3. 以浏览量、点赞、回复作为需求热度代理，不能直接当作商业成功；建议后续获取下载量、活跃设备、付费墙和留存。
