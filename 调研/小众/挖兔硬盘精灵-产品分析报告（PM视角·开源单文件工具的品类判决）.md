# 挖兔硬盘精灵（WatuDisk）— PM 视角分析
### 副题：一款「执行做对了 90%、商业结构上 0 分」的开源单文件工具，以及这类产品的通用判决

> **分析对象**：挖兔硬盘精灵 WatuDiskSprite v1.0.0 → v1.2.2（GitHub `fan138/WatuDisk`，GPL-3.0）
> **快照时间**：2026-10-22（GitHub API / Discourse API / 论坛与仓库原文实测）
> **分析目的**：**学它 + 判它**——「这类产品」的可行性结论，以及其中哪部分可迁移到自己的下一件事
> **分析叠加的方法论**：`产品分析框架`（七层提问法）→ `开源竞品与可复用能力.md`（先判死再省钱）→ `个人开发者方法论`（四道闸门顺序否决 + 12 维打分卡）→ `研究报告规范`
> **不重复造轮子**：品类底盘数据（CrystalDiskInfo 体量、HDS 定价阶梯、ARPU 断层、中文二手盘需求）已在本归档 `调研\工具\CrystalDiskInfo-产品分析报告（PM视角·商业化与赛道）.md` 中沉淀，本文只引用、不重算，新增的是**这个 28 天龄单品的一手数据**。
> **产品定位口径**：分析对象 = **单品**；结论外推到「类」时，明确标注「→ 品类」。
> **数据可信度**：本文数字逐条带标签（【实测·API】/【官方宣称】/【推算·方法X】/【预估·依据】/【未取得】），采集日统一 2026-10-22。

**本分析要回答的 3 个问题**

| # | 问题 | 判定性指标 |
|---|---|---|
| 1 | 这个产品本身有没有商业结构？ | 收入通道数、付费先例、盈亏平衡所需用户数 |
| 2 | 它做对了什么、做错了什么？错的部分是执行问题还是结构问题？ | 一手差评性质（可用/不可用/不敢用）、误报次数、留存信号 |
| 3 | 「这类产品」对个人开发者还开不开口子？开口在哪一格？ | 开源覆盖度等级（L0–L4）、免费替代通道数、频次×持续成本 |

## 〇、结论先行（TL;DR）

1. **这不是一个产品失败案例，是一个「结构注定收不到钱」的品类里执行最漂亮的那一档。** 24 天、7 个版本、盘面扫描（对标 HDS Pro 才有的 surface test）、30 个测试文件、`AGENTS.md` 项目治理、单文件绿色 + 离线只读 + 48 引擎查毒——工程质量远超同体量个人项目；但**收入 = ¥0，付费入口 = 0 个**，连打赏/赞助链接都没有。
2. **它 90% 的功能落在「公共品」里，只有 10% 在缝上。** 检测、显示、托盘、报警、HTML 报告 → CrystalDiskInfo（MIT，25 年，年下载 2,000 万+）与 Windows 11 内置 Drive Health 已经覆盖；真正只在它这里有的是「**20×20 盘面热力图 + 中文文艺提醒 + 自动体检评分**」——而这三样，两样是装饰，一样（盘面扫描）是 HDS 收 $33 卖的东西被它免费送了。
3. **杀伤力最大的一击不是竞品，是它自己 —— 一条差评直接把「安全工具」的信任前提打穿了。** 论坛 4 条外部发言里有 1 条是「**你这是要教我做人啊，吓得我赶紧删掉了，再找第三方工具把日志文件清理掉**」（强制开机自启取消不掉 + 历史报告删不掉 + 关闭按钮被屏蔽）。安全类工具靠"我信你才装"换安装量，一旦行为像 360，用户不是卸载，是**消毒 + 口碑反传**。
4. **它 20 天内出现了两次"寿命读数错误"，而这恰恰是它唯一自造的差异化指标（六档健康分）的命门。** 老金士顿 SV300 被判 0% 寿命（论坛 #2）、金士顿 SA400 显示"假 100%"而 CrystalDiskInfo 是 54%（v1.2.2 更新日志自述）。**自行发明评分口径 = 自行承担全世界硬盘固件的兼容性长尾**，而 CrystalDiskInfo 用 25 年 + 千万级样本才把这条长尾收到可接受范围。
5. **作者已经自己给出了判决：v1.2.2 起「功能定型，不再增加新功能」。** 距 v1.0.0 只有 24 天。这不是战略收缩，是**投入产出比在兴趣层面就崩了**——8 个被记录的"未纳入功能"（Linux / 趋势图 / i18n / USB 桥接 / RAID / SAS）里，前三个是外部用户真实提过的需求。
6. **免费层已经被 OS + MIT 开源 + 厂商官方工具三重覆盖，这一类产品的 ARPU 结构性趋零，收钱只能在「判定」和「验证」两格，不能在「显示」格。** 与既有 CrystalDiskInfo 报告的第四条启示完全同构（本归档第 5 次复现同一结论）。
7. **真正值得抄的不是产品，是「交付模板」：** 单文件绿色 + 离线只读 + 四源分发 + 48 引擎查毒 + `AGENTS.md` 给 AI 接手者写铁律 + 30 个回归测试。这套东西的可复用价值，远高于挖兔硬盘精灵本身。

## 二、它到底是什么（L1）

### 2.1 一句话定义（先不贴品类标签）

> **它把"硬盘会不会死"这件用户无法自证的事，翻译成一个颜色 + 一个分数 + 一句人话，并常驻在托盘里替你盯着。**

品类标签（陌生用户会把它放在哪）：「硬盘检测工具」→ 这个货架直接锁死竞品集合为 CrystalDiskInfo / HD Tune / Hard Disk Sentinel / 鲁大师硬件检测 / 图吧工具箱。**这是它最大的战略失误之一**：一进这个货架，它就是第 9 个免费选项。

### 2.2 最小可用内核

删掉所有包装后，用户为**一件事**装它：**开机后 3 秒内知道"我这块盘现在要不要备份"。**

其余全部是可删的：六档评分（三档够用）、200+ 条文艺文案（0 条也行）、7 步体检动效（不要更好）、HTML 报告（截图也行）、关盘守护（几乎无人依赖）。

### 2.3 Non-scope（它明确不做什么）

| 不做 | 商业含义 |
|---|---|
| 不写盘、不修坏道、不标记坏簇、不调 `chkdsk` | **主动放弃了 HDS 最值钱的那一格**（surface repair / Quick Fix），也放弃了"能解决问题"的付费理由 |
| 不联网、不收集数据、无账号 | 隐私卖点 = 商业化死角：无账号无法计费、无遥测无法运营、无云无复购触点 |
| 无云端黑名单 / 固件库更新 | 唯一可能有持续交付成本的能力被主动砍掉 → **订阅在结构上不成立** |
| 无多机管理 / 无 WMI/XML 输出 | 放弃了唯一有预算科目的买家（装机店 / 小型 IT） |

### 2.4 功能全景（四层分层）

| 层 | 功能 | 商业含义 | 判定 |
|---|---|---|---|
| **T1 内核** | SATA SMART 解析（80+ 属性字典）、NVMe 健康日志 IOCTL 直读、六档健康评分、专业指标网格 | 定价地基。**但地基是公共品**——同一块地基 CDI 免费给了 25 年 | ⚠️ 必须做对，做对了也不值钱 |
| **T2 增强** | 托盘常驻 + 图标变色、开机静默体检、关机守护、HTML 报告导出、指标「忽略」、历史记录 200 条 | 决定口碑，不该单独收费 | ✅ 做得不错，但都是 CDI/HDS 已有能力 |
| **T3 差异化** | ①20×20 盘面热力图（只读坏道扫描）②六档评分（自造口径）③200+ 条中文文艺提醒 ④"国产主控兼容" ⑤7 步 360 式体检动效 | 卖点来源，**必须逐个拿去和免费替代对撞** | 见 §6.2，5 条里 4 条对撞后归零 |
| **T4 长尾** | 提醒记录防打扰、护盘小贴士、五种提醒频率、固件版本显示、时段问候语 | 常是"看起来很强"的装饰 | 🔴 200+ 条文案 + 问候语是**场景错配**（用户要"要不要立刻备份"，不是读诗） |

**四层结论**：T1 是公共品，T2 是重复建设，T3 只有一条真（盘面扫描），T4 是自嗨。**功能数量看着多，可提取商业价值接近 0** —— 这正是框架里"功能是成本，不是价值"的标准样本。

### 3.3 用户分层

| 人群 | 场景 | 频次 | 付费意愿 | 该产品接得住吗 |
|---|---|---|---|---|
| 普通 PC 用户 | 电脑卡了 / 心里发慌 | 一年数次 | ≈0 | 接得住，但**接不住"不敢看"的那批**（见 3.4） |
| DIY 装机 / 维修店 | 验机、售后举证 | 每周多次 | 低（要免费绿色） | 接得住工具，接不住"批量 + 报告" |
| 二手盘买家 | 到手复测、维权 | 每笔交易 | **高（损失厌恶）** | ❌ 不接：报告不可举证、无清零盘识别 |
| 数据工作者（摄影/剪辑） | 素材盘寿命监控 | 持续 | 中低 | 部分接住（趋势图恰好没做，v1.2.2 明确不做了） |

### 3.4 最要命的一条：**用户在"不敢看"里流失，不在"不好用"里流失**

> 帖 #5 原话：「**东西是好东西，只是这玩意儿看着我焦虑症犯了啊，不敢下载**」

这句话的价值高于整个功能清单。它说明该品类的真实漏斗有一层**心理门禁**：

```
看见帖子 → ①"我需要吗"（多数人：不需要）
        → ②"知道了会不会更难受"（一部分人：会 → 主动回避）
        → ③下载 → ④第一次检测 → ⑤看到黄/红 → ⑥行动（备份/换盘）或 ⑦焦虑 → 卸载
```

WatuDisk 在产品设计上**主动加强了第②层**：六档颜色（比 CDI 三档多三档）、"千分之五概率"的官方话术、关机前复查 + 下次开机"郑重提醒"。作者的意图是"提高重视度"，实际效果是把一部分用户直接推出漏斗。**防灾类工具的通病：越有效，越让人不想面对。**

### 3.5 第二条要命：信任崩塌（唯一一次真实用户深度使用，以"消毒"收场）

> 帖 #7 原话：「**1.2 已经用上了，但是为什么对'开机自启'这么执着，无论如何都取消不掉。这次取消掉了，下次打开默认又勾选了'开启自启'。历史报告也删不了。……关闭按钮也屏蔽掉了不让点，只能点'明白了'。你这是要教我做人啊，吓得我赶紧删掉了，再找第三方工具把日志文件清理掉。**」

三件事叠加，性质变了：

| 行为 | 用户解读 | 品类的特殊代价 |
|---|---|---|
| 开机自启取消后下次又勾上 | "它非要待在我电脑里" | 硬盘检测工具要 **UAC 提权 + 常驻 + 读硬件**，用户对它的戒备本来就高于普通工具 |
| 历史报告删不掉 | "它留了痕" | 用户的联想是"它记了我什么"——**离线/只读/不留垃圾的卖点在这里被自己打脸** |
| 关闭按钮被屏蔽，只能点"明白了" | "它在教我做人" | 这是国产流氓软件的标志性交互，用户的条件反射就是"消毒" |

**PM 判决**：这不是细节 bug，是**定位与交互自相矛盾**。产品对外承诺「绿色 / 不留垃圾 / 尊重用户」，交互层却用了 360 那一套"仪式感 + 强制留存"。同一个产品里装了两套价值观，用户只会记住更差的那一套。（作者在 v1.2.1/v1.2.2 已逐条修掉，反应很快——但第一条被劝退的用户不会回来。）

## 四、价值主张与需求硬度（L3）

### 4.1 痛点 / 痒点 / 爽点判定

| 类型 | 对应功能 | 强度（P0–P5） | 判定 |
|---|---|---|---|
| **痛点** | "我的盘会不会突然死、我的数据会不会没" | **P3**（损失真实且不可逆，但概率低、发生前无体感） | 真痛点，**但用户不主动搜索它**——需要外部触发（卡顿/异响/朋友劝/买二手盘） |
| 痒点 | "想看看我机器的底细" | P2 | DIY/极客人群，付费意愿≈0 |
| 爽点 | 7 步体检动效 + 分数滚动 + 绿点呼吸 | P1 | 爽一次就腻，且**在安全类工具里是负资产**（像 360） |
| 优化点 | 报告导出、历史记录、忽略项 | P1 | 提效，不构成付费理由 |

> **P3 的含义**：真需求，但**频次与紧迫性都撑不起付费**。要收钱必须把它推到 P4–P5，而 P4/P5 的场景全在"已经出事了"之后（数据恢复、维权举证、批量运维）——**那三格它一个都不做**。

### 4.2 五条差异点 vs 免费替代（逐条对撞）

| 它宣称的差异点 | 对撞对象 | 对撞后还剩什么 | 判定 |
|---|---|---|---|
| **20×20 盘面热力图（只读坏道扫描）** | 免费层：HDDScan/Victoria（免费慢扫）、`chkdsk /r`；付费层：HDS Pro $33 | **还剩"图形化 + 单文件 + 中文 + 一键"**——是体验差异，不是能力差异 | ✅ 唯一站得住的差异化（但只值"更好用"，不值"要付钱"） |
| **六档健康评分** | CDI 三色灯（行业默认）、HDS 百分比 | **剩负数**：自造口径与行业不一致，用户第一次横向对比就困惑。README 自己都在写"为什么我给 92 分、某软件给 78 分" | 🔴 **需要解释的差异点 ≈ 不存在**（框架 L3.3） |
| **200+ 条中文文艺提醒** | CDI 声音/弹窗告警 | 剩"情绪价值" | 🔴 场景错配：报错时要的是结论与动作，不是文案 |
| **国产主控兼容** | CDI 的弱区 | 剩"部分国产主控字段能读" | ⚠️ 真缝，但**样本量决定一切**：他只有 668 次下载的用户基数，收敛不了这条长尾 |
| **离线 / 只读 / 单文件绿色** | CDI 便携 ZIP、smartctl | **剩 0** | ⚠️ 是**信任状**，不是差异点——它降低安装门槛，不构成"非它不可" |

### 4.3 反向证据（强制项）：它最自信的地方，恰恰是它出错的地方

| 时间 | 事件 | 来源 | 性质 |
|---|---|---|---|
| 2026-10-05 | 金士顿 SV300S37A240G（2013 老 SATA TLC）被判「**寿命 0%**」，用户原话「咋就给我硬盘干到只有 0% 寿命了」 | 论坛帖 #2 | **误报（假危险）** |
| v1.2.2（10-18） | 金士顿 SA400 被显示「**寿命剩余 100%**」，而官方工具与 CrystalDiskInfo 均为 54% | README 自述 | **误报（假安全）** ——比假危险更危险 |

> **这两次误报的性质必须分清**：假危险只是吓人；**假安全会让人放弃备份**。而它们的根因是同一个——**当固件不提供某项数据时，程序把"接口返回 0"当成了"零磨损"**。这类 bug 在这个品类里是无穷的：不同主控、不同固件年代、不同厂商私有字段。CrystalDiskInfo 用 25 年 + 千万级样本才把长尾收到可接受区间；一个人 + 668 次下载，**在数学上不可能收敛**。
> **这是本报告最重要的一条结构性判断**：它自造的"六档评分"把"读数据"（可对齐规范）升级成了"下结论"（要对全世界固件负责）。**差异化越自造，责任越无限**。

## 五、四道闸门（个人开发者 · 顺序否决）

| 闸门 | 判定 | 依据 |
|---|---|---|
| **① 收得到钱** | ❌ **不过** | 定位写死「免费 / 无广告 / 无赞助入口」，付费版 0 个，打赏链接 0 个。唯一留的口子是 README 的「双许可：需闭源商业授权请联系作者」——**但这产品的买家画像不存在**：会为一个免费替代品已存在的终端 GUI 工具买闭源授权的企业 ≈ 0。真正的双许可买家是"要嵌进商业产品"的**库**，不是工具。（对照 HDS：$22 买断卖的是修坏道，不是读数） |
| **② 扛得住成本** | ⚠️ **边际成本过，隐性成本不过** | 边际成本 ≈ 0 ✅（纯本地、无云、无 API）；但 **准确性长尾 = 无穷兼容性客服**。当前 1,000 用户量级只有 2 条外部 issue，看着轻松；若到 1 万用户，按技能 §一.5 的经验值（付费用户人均月提问 1 次 ≈ 每工作日 10 次请求）折算，一个人扛不住——而**这个品类的提问必然是"我的盘是不是要坏了"这种无法自助化的高情绪问题** |
| **③ 送得到人** | ⚠️ **勉强过，但只过一次** | "2 周内零预算让 20 个目标用户开口"→ 小众软件一帖做到 993 浏览 / 3 人开口 ✅；但**第二个渠道在哪？答不出**。四源分发（GitHub/Gitee/蓝奏/度盘）是同一批流量的四份拷贝，不是四个入口 |
| **④ 算得过账** | ❌ **不过** | 见附 B：加 Pro 墙后收入天花板 ¥142–¥1,283（一次性），远低于 24 天开发的工时机会成本 ¥1.8 万–¥3 万。要月入 ¥5,000 需月新增 5,263–8,772 用户，是实测水平的 5–9 倍且需持续 |

**闸门结论：1 不过 + 4 不过 + 2/3 勉强** → 按技能规则「前两道不过，后面的分析全部作废」。本文后续章节因此只做两件事：提炼可迁移做法、找品类里的真缝。

## 六、竞争位势与免费替代（L5）

### 6.1 竞争四层

| 层 | 谁 | 威胁度 |
|---|---|---|
| 直接竞品 | CrystalDiskInfo（免费 MIT）、Hard Disk Sentinel（$22 起） | 🔴 极高——一个占了"免费+标准"，一个占了"付费+动作" |
| 间接竞品 | 鲁大师 / 360 / 电脑管家（硬件检测模块）、图吧工具箱 | 🟡 中——抢的是"普通用户第一次想检测硬件"的入口 |
| **免费替代（最强层）** | Windows 11 内置 Drive Health、`wmic`、smartctl、LibreHardwareMonitor、厂商工具 ×6 | 🔴 极高——**这一层决定天花板** |
| 用户自己动手 | `wmic diskdrive get status`、事件查看器、忍着 | 🟡 中 |

### 6.2 开源覆盖度五级判定（强制项）

| 能力段 | 覆盖度等级 | 依据 | 结论 |
|---|---|---|---|
| **NVMe 健康读数** | **L4 被 OS 官方免费覆盖** | Windows 11 设置页直出"预估剩余寿命 / 可用备用 / 温度"；PowerShell 可取 | ⛔ 直接砍 |
| **SATA/HDD SMART 读数与展示** | **L3 有活跃成品** | CrystalDiskInfo 9.9.3（MIT，2026-10 仍在更新，年下载 2,000 万+，Uptodown 单渠道累计 1,034.19 万） | 🔴 只做它明确不做的那段 |
| 盘面坏道扫描 | **L1/L2 之间** | 免费有 HDDScan/Victoria（体验旧）、付费有 HDS Pro；**没有"单文件 + 中文 + 图形化热力图"的免费成品** | ✅ **这是唯一的位置** |
| 假盘/清零盘/扩容盘判定 | **L0–L1 未覆盖** | CDI 9.9.0 才刚加 `[FAKE]` 规则雏形（靠用户投稿），免费层无人做清零盘逻辑矛盾检测 | ✅ **需求最强、供给最弱的一格**（既有报告已论证） |

> **综合判定：L3.5** —— 检测展示段 L3、NVMe 段 L4、判定/验真段 L0-L1。**WatuDisk 把 90% 的工程量投在了 L3/L4 那两段**，这解释了为什么它做得越好、越收不到钱。

### 6.3 差异点层级（越靠后越难被抄）

| 层级 | 它站在哪 | 可守性 |
|---|---|---|
| 功能 | 盘面扫描、六档评分 | 3 个月（一个周末能抄） |
| 体验 | 单文件、绿色、中文、一键 | 6 个月 |
| 价格 | 免费（自己砍到 0） | — |
| 人群 | 未选定 | — |
| 渠道 | 小众软件 + GitHub | 一次性 |
| 品牌 | 「挖兔」系列（下载器 + 硬盘精灵） | 早期，无认知 |

**它没有一层守得住。** 在这个品类里，唯一能守的是"CrystalDiskInfo 用了 25 年攒下的社会惯性（大家都发它的截图）"——而这个东西买不到、抄不来、只能等，个人开发者等不起。

### 6.4 系统内置威胁（本层最该看的一条）

Windows 11 已经把"NVMe 剩余寿命 + 温度 + 备用空间"搬进设置页。**微软的动作是逐版本扩面**：从 `wmic` 的布尔值 → 设置页的百分比。这意味着：

> **这个品类的"显示"层正在被 OS 逐格回收。** 今天的缝是"老 SATA 盘 + 国产主控 + 坏道可视化"，明天的缝只会更窄。任何以"显示得更清楚"为核心价值的工具，都在跟微软的版本节奏赛跑——**而个人开发者的更新频率永远追不上 OS**。

## 九、品类判决：这类产品的六个结构特征与开口

### 9.1 「这类产品」的定义

| 5 | **别把"功能定型"当战略** | 24 天定型 = 承认投入产出比崩了。若要持续，必须一开始就把"可持续的维护成本"设计进产品（黑名单/型号库/报告服务） |
| 6 | **别同时开两个产品线** | README 自述"挖兔下载器的兄弟产品"——个人开发者的时间预算是"每年只能认真做一件事"（技能 §一.3） |

### 9.5 如果一定要进场：唯一的开口与最小验证

| 位置 | 为什么是缝 | 谁付钱 | 最小验证（只认行为） |
|---|---|---|---|
| **A. 假盘 / 清零盘 / 扩容盘判定**（不做读数，做结论） | 免费层全部只能被动读 SMART，清零盘的 SMART 反而漂亮；CDI 的 `[FAKE]` 只是规则雏形且靠用户投稿。**需求最强、供给最弱**（既有报告已论证） | 二手盘买家（损失厌恶峰值：一块假 2TB = 数据全毁） | 在闲鱼/什么值得买发"免费帮看盘"帖，人工收 20 份截图做判定 → 看**多少人愿意为"结论"付 ¥10**（人肉代做 → 直接收钱） |
| **B. 验机/举证型报告**（可核验、带时间戳、防篡改） | 用户原话"静态截图可以伪造，要求拍带当天日期的视频"——**可举证是明说出来的痛点** | 二手交易双方、维修店、售后维权 | 先做"报告生成器"，不碰检测：让用户上传截图 → 输出带时间戳哈希的验机单 → 测有没有人愿意付 ¥5/次 |
| **C. 批量巡检（装机店 / 小型 IT）** | 缺集中管理是明确空位（HDS Enterprise 从 $219.50 起，对 10–50 台规模过重） | 装机店、二手商家、小型 IT | 找 3 家本地装机店，人工代做"多机巡检表"两周 → 看是否愿意为自动化付年费 |

> **三条的共同点**：都不在"显示"格，都在"判定/验证/批量"格；都**有持续交付成本**（黑名单、报告存证、多机管理），所以订阅/年费在结构上成立——这是与 WatuDisk 最根本的分野。
> **但三条都要过同一道门禁**：频次。二手盘买家一辈子买 2–3 次盘 → 只能买断或按次，**收不了订阅**。所以正确的形态是「**按次/买断 + 高单价**」，不是「年费 + 低单价」。

## 附 B、测算过程与敏感度（与实测分开排版）

> 纪律：每个推算写 **假设 → 依据 → 推算 → 结果**，并给置信度与推翻条件。

### B1 独立用户数（去重）

| 段 | 内容 |
|---|---|
| 假设 1 | GitHub 668 次下载对应 534 名独立下载者（÷1.25 重复系数） |
| 依据 1 | 7 个版本、24 天内迭代频繁，跟随升级的用户平均下载 2–3 次；但多数路人只下一次 → 取 1.25 |
| 假设 2 | Gitee + 蓝奏 + 度盘 合计 = GitHub × 0.60 |
| 依据 2 | 作者把国内源列为主推；但无任何计数器 → 系数纯属估计 |
| 推算 | 534 + 534×0.60 = 534 + 320 = **854** |
| 交叉校验 | 作者口径"一千多个用户"= 4 源累加未去重（668 + 320 + 首发其它 ≈ 1,000+）→ 与推算自洽 |
| 结果 | **独立用户 ≈ 800–1,200，P50 ≈ 1,000** |
| 置信度 | 中 |
| 推翻条件 | 若拿到蓝奏/度盘的真实下载数，且合计 > GitHub × 1.5，则用户数上修至 1,500+ |

### B2 若加 Pro 墙：收入天花板（一次性）

| 段 | 内容 |
|---|---|
| 假设 1 | 付费率 3% |
| 依据 1 | 免费工具加 Pro 墙的常见区间 1%–5%；本赛道无中间态样本（CDI 全免费、HDS 纯付费），取中值 |
| 假设 2 | 客单价 ¥19 买断 |
| 依据 2 | 锚点：HDS $22 太高（远超国产小工具心理价位）；国内单点工具主流 ¥9.9–29 |
| 推算 | 1,000 × 3% × ¥19 = **¥570**（一次性，非年化） |
| 结果 | **P50 ¥570；区间 ¥142 – ¥1,283** |

**敏感度（双因素，看结论是否翻转）**

| 付费率 \ 用户数 | 500 | 1,000 | 2,000 |
|---|---|---|---|
| 1.5% | ¥142 | ¥285 | ¥570 |
| **3.0%** | ¥285 | **¥570** | ¥1,140 |
| 4.5% | ¥427 | ¥855 | ¥1,710 |

> **结论不翻转**：全表最高 ¥1,710，仍低于 24 天开发的工时机会成本（B4：¥1.8 万–¥3 万）。**结论稳健**（稳健的否定结论，正是可以放心执行"不做"的依据）。
