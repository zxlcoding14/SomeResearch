> 分析对象：`场景池穷举总表` 中的 J1（律师卷宗/证据梳理）

## 〇、结论先行（TL;DR）

1. **卷宗这件事能拆出 12 个可做的动作，但只有 3 类值得做**：① 卷宗批处理（水印 PDF/图片型 PDF → 可检索双层 PDF + 页码锚定）；② 证据编目与缺口检查（要件事实 → 证据目录 → 缺什么）；③ 归档命名与案件台账。其余 9 类（文书起草、类案检索、合同审查、录音转写、计费、客户门户等）都已被免费或大厂产品占死。
2. **适合做 Windows 工具，但只能做「单点工具」，不能做「案件管理套件」**——律所已有 Alpha/律呗/无讼类系统，正面做套件必输。Windows 是律师主战场（PDF/Word/WPS + 本地卷宗 + 可离线），且本地推理把边际成本压到 ≈0，是这个方向唯一能挂年费的技术路径。
3. **最大发现（也是对原研判的修正）：我原本设想的「Windows + 本地 + 便宜」这个位置已经被占了**——圆周律πLex 提供 Windows/macOS 桌面版、本地存储、断网可用、免费，功能已覆盖时间线/证据目录/证据缺口/文书初稿（用户自备大模型 API Key）。叠加腾讯智审（对律师免费、自动生成证据目录）与 WPS 365（¥599/人/年含 AI 编目+时间轴+法律关系图+私有化部署），**J1 的分数从 96 下调到约 90，结论从「升格立项」改为「继续做，但产品假设必须收窄成楔子」**。
4. **剩下的楔子只有三个，且都不在任何一家现有能力域里**：① 零配置（不填 API Key、装完就能用、内置额度、可离线）；② 案由专用要件矩阵模板库（民间借贷/买卖/劳动/道交/婚姻/常见罪名）；③ 团队模板统一与归档合规（卖席位而非卖个人）。
5. **付费场景有 6 个，最硬的两个是「开庭前按案件付费」与「律所 5–20 席年费」**，最软的是「个人年费订阅」。定价锚点现成：国内按案 ¥50/案（智元法律）、年费 ¥980–¥1,500（律呗/贤律助）、WPS ¥599/人/年；海外按页/按案件 $99/月（≈¥703/月）起。
6. **否定性结论：靠「AI 帮你读卷宗」这个卖点活不下来**——免费产品已经在做，大厂在打包。能卖的只有「脏活自动化 + 模板资产 + 团队一致性」。如果做不出模板资产，这个方向应该直接放弃。

## 一、律师拿到卷宗后的真实动作链（8 环节）

## 三、明确不做的五件事（做一件就死）

1. **法律意见/胜诉率预测**——触碰执业边界与合规红线（AI 编法条、编案例已有翻车案例）。
2. **通用文本生成（起诉状/代理词一键成稿）**——通用大模型免费，且律师必须逐句改，价值低于预期。
3. **类案检索**——秘塔免费、裁判文书网权威，无空间。
4. **案件管理套件**——撞 Alpha/律呗/无讼 + 律所已有采购。
5. **录音转写/庭审速记**——D1 域已判死（通义听悟、飞书妙记免费）。

## 四、Windows 工具适配性判断

### 4.1 为什么适合（5 条）

| 理由 | 依据 |
|---|---|
| 律师办公几乎全在 Windows + Office/WPS | 卷宗处理天然是桌面场景（本地大文件、扫描仪、批量打印）【推算·行业常识，待访谈确认】 |
| 卷宗是本地文件，不是网页数据 | 拖拽/右键/资源管理器集成是最高频入口 |
| 保密义务逼出「本地优先」 | 律师执业保密义务 + 个人信息保护法；本地处理是**卖点不是妥协** |
| 本地推理把边际成本压到 ≈0 | C 端 AI 产品唯一能挂年费的技术路径（算力由用户承担） |
| 离线可用 | 法院内网、外出开庭、异地阅卷场景 |

### 4.2 七个坑（每个都能让上线首月崩溃）

| # | 坑 | 应对 |
|---|---|---|
| 1 | **杀软误报**（律师电脑 360/火绒标配），含本地模型的 exe 极易被拦 | 买代码签名证书（约 ¥1,000–¥3,000/年【预估·依据：行业常见报价，未核】）+ 提交白名单 |
| 2 | 法院 PDF 常**加密/禁复制/带水印**，通用库直接抛异常 | 自研容错解析链路 + 明确「不绕过加密、仅处理已授权文件」的合规章述 |
| 3 | WPS 与 Word 双生态，格式兼容是客服黑洞 | 输出只走「PDF + xlsx/docx 最小公共集」，不做复杂样式 |
| 4 | 1GB 级卷宗导致内存/索引爆炸 | 流式处理 + 分卷索引 + 进度可中断续跑 |
| 5 | 没有自动更新通道 → 客服成本指数上升 | 首版就上自动更新 + 崩溃日志回传 |
| 6 | 只有 Win 版会丢一部分青年律师（Mac 占比上升） | 先 Win，架构上把引擎与 UI 分离，为 Mac 留口 |
| 7 | 本地模型包体 2–8GB，下载转化率暴跌 | 小安装包 + 模型按需下载（可选云端额度兜底） |

### 4.3 形态建议

- **形态**：Windows 单点工具（安装包 < 100MB，模型按需下载），入口 = 资源管理器右键 + 拖拽 + 常驻托盘。
- **架构**：本地优先（PDF 处理 100% 本地；抽取与归纳默认本地小模型）＋ 可选云端增强（大模型额度，明示「数据是否出本机」）——**默认本地，云端要用户手动开**，这是对律师最有效的信任设计。
- **不做**：多端同步、团队协同（首版），那是套件逻辑，会把支持面撑爆。

## 五、付费场景（6 个，按「付费时刻」硬度排序）

| # | 场景 | 谁付 | 付费时刻 | 定价锚点 | 硬度 |
|---|---|---|---|---|---|
| 1 | **按案件付费** | 独立执业/青年律师 | **开庭前 3 天**（最痛的时刻） | ¥29–¥59/案（对标智元法律 ¥50/案【二手·实测文】） | ★★★★★ |
| 2 | **律所席位年费** | 合伙人/律所主任 | Q4 预算、新所建库 | ¥399–¥999/席/年（对标 WPS ¥599/人/年、律呗 ¥980/年） | ★★★★☆ |
| 3 | **个人年费** | 独立律师 | 试用到期、案件量上来 | ¥299–¥499/年（对标 ¥980–¥1,500 的下沿切入） | ★★★☆☆ |
| 4 | **批量页数包** | 大案团队 | 一次性几百页卷宗 | ¥0.05–¥0.20/页（对标通义法睿 ¥4/页，做低价替代） | ★★★☆☆ |
| 5 | **模板/案由库订阅** | 青年律师 | 换所、接新案由 | ¥99/年（内容资产，边际成本≈0） | ★★★☆☆ |
| 6 | 定制交付（律所模板对齐） | 律所 | 采购谈判 | ¥3,000–¥10,000/项目 | ★★☆☆☆（**人力活，个人慎接**） |

**关键判断**：第 1 项（按案件）是这个方向最被低估的付费场景——**律师不是不愿付费，是不愿为「还没用上的年费」付费**；开庭前的焦虑点愿意为一次 ¥30 立刻掏钱。首版定价建议「按案件为主 + 年费兜底」，而不是只做订阅。

**盈亏粗算【推算·锚点反推】**：假设年费 ¥399/年（≈$56）、单用户变动成本 ¥60/年（云端额度）→ 年毛利/单 ≈ ¥339；月固定成本 ¥300（服务器+签名+域名）→ 盈亏平衡 ≈ **11 个付费用户**。若按案件 ¥39 计、法院文件处理近乎零变动成本，则 **每月 8 单** 即可覆盖固定成本。敏感度：固定成本 ±50% → 6–17 人，结论稳定。
