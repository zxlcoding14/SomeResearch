# 新方向探索：AI 原生高频小工具场景（2026-10）

> 定位：不覆盖传统小工具既有格局（PDF/压缩/录屏等传统赛道见另篇全景表），只探索 **AI 原生的新场景/新工作流方向**。
> 方法：场景假设 → 竞品/拥挤度验证（2026-10 公开数据）→ 空白点 → 待证伪信号。
> 价格均为公开列表价，实际以官方为准。

---

## TL;DR

1. **录屏 → SOP/操作文档**是当前信号最强的新方向：海外已验证 B 端付费（Scribe $25/人/月、Tango $22/人/月、Guidde $19~39/人/月、Glitter AI、Trupeer 共 5+ 玩家全在收费），**国内桌面本地化版本近乎空白**，且天然需要本地化（录屏含隐私）。
2. **AI 文件语义整理/重命名**：2026 年已进入**红海早期**——国际 7+ 付费玩家（Renamer.ai、Sortio、FilesDesk、NameQuick、Zush…）+ 国内免费开源潮（WisFile 免费、AI File Sorter 开源、FolderFox）。**不要再正面进入**，只能做垂直切口（如发票/合同专向）。
3. **截图 → 结构化数据**：通用"截图转 Excel"已被免费在线工具（image2excel.app 无限量免费）+ 微软 Excel 内置"Data from Picture"覆盖，**通用版死路**；空白在垂直结构化（记账凭证、报关单、病历、代码片段库）。
4. **桌面 AI Agent/本地知识库**：腾讯 Marvis、阿里千问办公、有道 LobsterAI、牛马AI 等已爆发"大厂大战"，个人/小团队**规避正面**，但可以寄生在其没有的小切口上（垂直行业工作流）。
5. **桌面屏幕记忆（Personal AI Memory）**：屏幕+语音持续捕获→可搜索/可问答的个人记忆层。海外已分化（screenpipe 本地开源 $25/月、微软 Recall 内置、Limitless 被 Meta 收购、Granola $14/月），**国内尚无成熟产品**，且该品类天然强隐私需求（local-first 是结构性差异）——但需警惕微软 Recall 的 OS 内置挤压。
6. **截图/屏幕自动脱敏（AI 打码）**：海外已有 10+ 玩家（BlurData、Shhshot、Xnapper、CleanShot X AI cleanup、Snagit 智能脱敏等），且头部截图工具正把"AI 脱敏"当功能内嵌——**独立产品窗口正在关闭**，更适合做功能而非产品。
7. **机会筛选铁律**（本轮验证沉淀）：非结构化输入 × 垂直输出结构 × 本地隐私敏感 × 大厂不做的脏活 = 可探索方向；输入是通用格式 + 输出是通用格式 = 必被免费/内置覆盖。
8. **全景候选矩阵**：除已验证的 7 个方向外，另按 8 大域收录 30+ 候选场景并标注状态（见第八节），覆盖创作、捕获、文件、隐私、音频、交互、开发、跨端、垂直行业全部新场景线索。

## 一、方向 1：录屏 → SOP/教程文档（信号最强 ★★★★★）

### 1.1 场景

用户正常操作软件（录屏），AI 自动产出：带截图标注的分步文档（SOP）、带旁白的教程视频、可交互的新手引导。人群：中小团队运营/客服/IT 培训、自媒体教程作者、外包交付团队。

### 1.2 竞品与拥挤度（海外已验证，国内空白）

| 竞品 | 公司/背景 | 模式 | 定价 | 特点 |
|------|----------|------|------|------|
| Scribe | 独立（美国） | 浏览器/桌面自动捕获点击→生成图文指南 | 免费 + Pro $25/人/月（团队 $13/人/月） | 品类第一心智；免费版仅网页录制 |
| Tango | 独立（美国） | 同上+交互式引导 | 免费（不限条数）+ Pro $22/月 | 免费层最大方；桌面捕获付费 |
| Guidde | 独立（美国） | 视频优先：录屏→AI 旁白视频+图文 | 免费 25 视频 + $19~39/创作者/月 | 视频+文档双输出 |
| Glitter AI | 独立（美国） | 边说边点→语音转步骤，99 种语言 | 免费 10 份 + $16~20/月 | 语音解说捕捉"为什么" |
| Trupeer | 独立 | 粗录屏→润色脚本+AI旁白+缩放 | 免费 10 天 + $40/月 | 视频精修路线 |
| Loom（对标参照） | Atlassian | 录屏分享，不做 SOP | 免费+Pro | 验证录屏协作需求规模 |

**国内现状**：360（EV录屏/苏打录屏）、剪映等均停留在"录制/剪辑"层，无"录屏→SOP 文档"产品；钉钉/飞书妙记做的是"会议纪要"不是"操作文档"。**国内市场基本空白，但品类教育可借海外 Scribe 的心智。**

### 1.3 空白点与切入角

- **国内版 Scribe**：中文软件生态（微信/钉钉/金蝶/用友）的流程文档化，海外产品做不了。
- **本地化隐私**：录屏常含客户数据，纯本地推理是差异化（海外全线云处理）。
- **输出垂直化**：客服话术库、软件验收文档、外包交付文档——按行业打包。

### 1.4 待证伪信号（falsify 清单）

- 国内用户是否愿为"操作文档生成"付费（海外是 SaaS B 端心智，国内 B 端付费习惯弱）；
- 搜"操作手册 自动生成/教程文档 工具"的搜索量与社区抱怨密度；
- 钉钉/飞书 6~12 个月内是否内置该能力（大厂挤压风险）。

## 二、方向 2：截图 → 垂直结构化数据（★★★☆☆）

### 2.1 场景

截图/照片 → 直接产出**业务可用**的结构化数据。通用"截图转 Excel"已死，但垂直场景的"截图即录入"仍有空间。

### 2.2 竞品与拥挤度

| 竞品 | 公司 | 定价 | 覆盖 |
|------|------|------|------|
| Excel「Data from Picture」 | 微软内置 | 免费（M365内） | **通用场景最大免费替代** |
| image2excel.app / Utilvo / OCR2Excel | 独立/开源 | 免费无限量（浏览器本地推理） | 通用截图转表已免费化 |
| Nanonets / Energent.ai / FormXAI | 独立 SaaS | $49/月起（Energent） | 企业级批量发票/单据 |
| 扫描全能王 | 合合信息（688615） | 免费+会员 | 移动端扫描+表格 |
| SnapTable | 开源（GitHub） | 自托管免费 | PaddleOCR 方案开源化 |

### 2.3 空白点

- **截图记账/凭证录入**：微信支付宝账单截图→记账软件直接入库（个人记账 + 小商家流水）；
- **行业单据专精**：报关单、物流面单、病历处方、施工签证单——通用 OCR 不做行业字段映射；
- **截图→代码/公式**：截图 UI→前端代码、截图公式→LaTeX（已有零星工具，未形成心智）。

### 2.4 待证伪信号

- 目标垂直人群的截图录入频率（每周 ≥5 次才值得装常驻工具）；
- 与手机端（扫描全能王）的生态错位：桌面端批量截图场景是否真实高频。

## 三、方向 3：AI 文件语义整理/重命名（拥挤警告 ★★☆☆☆）

### 3.1 竞品与拥挤度（2026 年已红海早期）

**国际付费梯队**：Renamer.ai（$9.95~99.95/月，按文件数计量）、Sortio（$14.99/月，AI Rule Builder 架构佳）、FilesDesk（$8~40，离线 OCR）、NameQuick（$12/月，监听邮箱发票）、Zush、RenameClick、Friday（Mac $4/月）、Kalycs（Mac 买断）。
**开源/免费潮**：AI File Sorter（开源，本地 Gemma 3 4B 视觉模型、dry-run+撤销）、GhostFile Agent、FolderFox、WisFile（国内，免费）、Paperless-ngx+AI（文档全生命周期）。

### 3.2 结论

- 品类已被验证（付费模型成立），但 2026 年内涌入 10+ 玩家且开源免费方案体验已可用——**正面进入胜率低**。
- 残余切口：**垂直单据流水线**（发票→记账软件自动归档，NameQuick 的 inbox 模式已验证此方向）、NAS/外置盘冷数据治理（AI File Sorter 的 NAS 流程是新出现的定位）。

## 四、方向 4：桌面 AI Agent / 本地知识库（规避正面 ★☆☆☆☆）

### 4.1 拥挤度（2026 年爆发的大厂大战）

- **大厂**：腾讯 Marvis（系统级操控+端云双模）、阿里千问办公 QwenWork（三形态合一）、网易有道 LobsterAI（MIT 开源+沙箱试跑）、实在 Agent（老旧系统 RPA）。
- **开源/独立**：AnythingLLM、GPT4All、Jan、LM Studio、Open WebUI、牛马AI（全离线）、AiPy（代码即代理）。

### 4.2 残余机会

- 大厂做"通用 Agent 平台"，**垂直行业工作流**（律师卷宗、财务月结、跨境电商多平台运营）的"脏活封装"仍空缺；
- 但这已不是"小工具"，是垂直应用——超出 mini-tool 范畴，仅作方向记录。

## 五、方向 6：桌面屏幕记忆 / 个人 AI 记忆层（★★★★☆）

### 6.1 场景

常驻后台持续捕获屏幕内容+系统声音，OCR/转写后存为本地可搜索数据库——"我上周看过的那个报价单在哪"、"这个月谁在哪个会里说过预算"，并可驱动 Agent 自动产出周报/跟进/SOP。人群：知识工作者、销售/客服、开发者、研究岗。

### 6.2 竞品与拥挤度（海外已分化，国内空白）

| 竞品 | 公司/背景 | 模式 | 定价 | 关键事实 |
|------|----------|------|------|---------|
| screenpipe | 独立（YC 孵化） | 本地常驻捕获（屏幕+音频），source-available，REST API/MCP 供任意 AI 调用 | 免费层 + $25/月起 | 100% 本地、可自托管、可审计；品类的本地化标杆 |
| Windows Recall | 微软内置 | Win11 Copilot+ PC 截屏索引，端侧 AI | 免费（随系统） | **OS 级内置=最大变量**；仅限带 NPU 的新硬件；2026-03 曾曝安全提取事故 |
| Limitless（原 Rewind AI） | **2025-12 被 Meta 收购** | 硬件吊坠+云处理 | 硬件 $99 + $20~49/月 | 硬件已停售，转向 Meta 生态；验证了赛道价值 |
| Granola | 独立 | 会议转写+屏幕上下文，云端 | 免费 + $14/月 | 会议为中心 |
| Mem0 / Zep / Letta | 独立开发者基建 | AI 记忆层 API（非桌面 C 端） | API 计费 | 佐证"记忆"是行业级需求 |

### 6.3 空白点与切入角

- **国内版本地屏幕记忆**：Recall 仅覆盖 Win11 Copilot+ 新机（国内保有量极小），screenpipe 无中文产品化；国内用户对"上传云端"极度敏感 → **local-first 中文产品**有结构性空位。
- **合规敏感行业**：律所/金融/政企的"本地记忆+审计"，大厂云端方案进不去。
- **风险**：OS 厂商（微软/苹果/国产 OS）最终内置；腾讯 Marvis 已有"本地文件 AI 搜索"，但未做"屏幕内容记忆"。资源占用（CPU/电池/存储）是用户流失主因，产品门槛真实存在。

### 6.4 待证伪信号

- 国内用户对常驻录屏的接受度（历史包袱：安全软件污名）；
- 目标人群周检索"我看过的内容"频次；
- 微软 Recall 中文市场渗透速度、国产 OS 是否跟进。

## 六、方向 7：截图/屏幕自动脱敏（AI 打码）（★☆☆☆☆ 窗口正在关闭）

### 6.1 竞品与拥挤度

- **独立产品**：BlurData（Mac，$4/月）、Shhshot（免费）、BlurScreen App（买断）、Redact.ai / pixolution.ai（在线）、Blur.me（NT$299/月）等 **10+ 家**。
- **被内嵌化**：CleanShot X "AI cleanup"、Snagit 智能脱敏、Xnapper（买断）、苹果 Visual Intelligence——头部截图工具已把"自动打码"当功能集成。
- **结论**：海外付费模型存在但小（$4~12/月档），且正被截图工具吸收为 feature；**国内作为独立产品窗口很窄**，建议降级为其他截图类产品的内置功能（如方向 2 截图工作流的子能力），不单独立项。

## 六、本轮沉淀的筛选铁律（screen 阶段直接复用）

1. **输入×输出双通用 = 死路**：通用格式转换（截图→Excel、PDF→Word）必被免费在线工具/微软内置覆盖。
2. **付费已验证 + 玩家 < 3 家国内 = 黄金窗口**：录屏→SOP 即此形态（海外 5 家收费、国内 0 家）。
3. **付费已验证 + 国内开源潮 = 红海早期**：AI 文件整理即此形态，只做垂直切口。
4. **大厂 Agent 平台大战中，做"平台没做的垂直脏活"**，不做平台本身。
5. **本地推理/隐私是独立产品对大厂唯一的结构性差异**：录屏、凭证、卷宗、健康数据场景优先。

## 七、下一步（falsify 阶段建议动作）

1. 对方向 1（录屏→SOP）：用真实数据验证——百度/微信指数、"Scribe 国内平替"搜索词、小红书/B站"写操作文档"抱怨内容抽样、3~5 个目标 B 端用户访谈（客服/IT 培训岗）。
2. 对方向 2 垂直切口：选定 1 个行业单据（建议记账/发票），抽样竞品（Nanonets 等）收入样本法估算付费规模。
3. 对方向 3：仅保留"发票→记账软件"切口进入候补，其余放弃。

## 九、全景优先级排序（screen 阶段输入）

综合「付费验证度 × 国内空白度 × 本地隐私红利 × 大厂挤压风险」四因子：

1. **录屏→SOP**（方向 1）：四项全占优，唯一大风险是钉钉/飞书内置——建议 3 个月内完成 falsify。
2. **桌面屏幕记忆**（方向 6）：付费与需求已验证（Meta 收购 Limitless 佐证），国内+硬件覆盖双空白；风险是资源占用与接受度，产品门槛高。
3. **发票/凭证流水线、录屏→交互式 Demo**（8.8/8.1）：垂直切口，付费意愿真实，需小样本验证。
4. 其余 🟡 场景：作为上述方向的功能扩展储备，不单独立项。
5. 🔴 场景：不再投入。
