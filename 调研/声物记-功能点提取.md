## 一、软件定位

- **开源**：代码托管在 GitHub
- **纯本地 / 离线**：使用离线语音模型，全程不用联网，不上传用户任何数据
- **免注册**：无需账号
- **免费**：现阶段功能全免费（仅放打赏码）
- 双重身份：**语音物品管理** + **闪念胶囊（语音速记）**

## 二、核心功能特性

### 1. 物品管理
- **语音存物品**：长按录音说「洗发露在 3 号箱子」「牙刷在厨房小推车」，自动拆分为「物品 — 位置」结构并存档，不用打字
- **语音查询（双重查询）**：
  - 按物品查位置：「电风扇在哪」→ 电风扇在桌子上
  - 按位置查物品：「客厅里有什么」→ 客厅里有收音机
- **技术注意点**：存物品依赖关键字识别【在】/【放在】，说话需包含这两个字

### 2. 搬家模式（解放双手，持续录音存物品）
- **语音反馈**：识别成功朗读「已把牙刷放入绿色箱子」，失败有提示音，不用盯屏幕
- **语音纠错**：说「这条不对 / 撤销」可自动删除上一条记录

### 3. 语音笔记 / 闪念胶囊
- **长按音量键** → 快速启动 app 并开始录音，再次长按即转写为文字
- **双击音量键** → 直接新建文本笔记，键盘自动拉起
- **亮屏即触发**：未解锁状态下也能正常录音并转写
- 离线转写，全程无网络依赖

## 三、产品设计亮点（PM 视角）

- 零门槛交互：语音驱动「存 + 查」闭环，覆盖搬家整理、日常收纳、随手速记场景
- 硬件级快捷入口（音量键）替代桌面图标启动，降低启动摩擦
- 离线 ASR + 关键字规则解析，用轻量方案替代云端 NLP，隐私与成本双优
- 语音朗读反馈 + 撤销指令，适配「双手忙碌、不看屏幕」的使用环境
