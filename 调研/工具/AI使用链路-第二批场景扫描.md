# AI 使用链路 · 第二批场景扫描（2026-10-23）

> 接续《AI使用链路痛点与工程化方向-机会扫描.md》（首轮 12 场景）与《AI使用链路-逐场景核查与可行性结论.md》（统一核查）。
> 本轮问题：**链路下还有哪些可尝试的新场景？** 候选池 8 个，全部按同一方法（信号采集 → 开源雷达 → 付费竞品 → 覆盖度五级 → 闸门初判）核查。
> 数据纪律：数字全部标注口径与级别；采集日 2026-10-23，除特别注明。

---

## TL;DR（结论先行）

1. **第二批 8 个候选场景，0 个幸存为「个人可直接立项」**。幻觉包防护、MCP 审计、规则文件同步、注入防火墙、Agent 回滚、会话→评测、用量监控、会话归档——每一个开源供给端都已挤进 3–6 个免费实现，且多数是近 12 个月内新出现的。
2. **结构性规律（本轮最重要产出）**：AI 使用链路的**显性痛点（会被公开讨论的那种）开源填平周期 < 6–12 个月**。痛点一旦在博客/论文/HN 出现，几个月内就有 5+ 免费实现跟进。**「做一个开源没有的工具」在链路层已不是有效策略**。
3. 三轮扫描合并后，**幸存者仍是前两轮那两个，且模式相同**：RAG 体检 GUI 化（库→产品空位）、本地部署安全「修复段」（检测段判死、修复段空位）。这两个的共同点是：**开源只做了「检测/库」，没人做「修复/交付结果」**。
4. 因此本轮真正的增量不是新场景清单，而是一条可复用的判据：**检测/审计类单点工具注定免费且窗口期 < 6 个月；「从检测走向修复、从库走向结果交付」的位置才有付费空间。** 已写入方法论备忘。

|---|---|---|---|

## 三、逐场景要点（补充细节）

**N1 幻觉包防护**：需求证据最硬——USENIX Security 2025 研究：16 个模型生成 223 万代码样本，**19.7% 引用了不存在的包**（20.5 万个唯一假名），**43% 的假名在 10 次重跑中稳定复现**【二手·论文】——即系统性可被 slopsquatting 攻击注册。但供给端响应极快：ExactGround 已做到「PreToolUse hook 拦截每次 install + manifest 校验 + 建议 Correct 名称」，且明确哲学是「CLAUDE.md 里写规则是模型可能忽略的文本，hook 是每次都跑的代码」——这个洞察本身就是该场景的正确产品形态，已被占。个人再进只剩「把 4 个免费工具做 GUI」，无付费逻辑。

**N2 MCP 审计**：痛点数据漂亮（约 7,000 个公开 MCP 服务器中 41% 无鉴权、36.7% SSRF 可利用、仅 8.5% 用 OAuth【二手·需交叉】），但工具供给已「内卷到零依赖手写 tar 解析器」的程度（mcpaudit 的自述）。安全扫描器的宿命与首轮 docling 结论一致：**有 GitHub Action 生态在，单机审计工具没有独立产品位**。

**N3 会话归档**：唯一出现 **GUI 成品**的场景——Hindcast（作者自述个人存档 114 会话 / 65 项目 / 0.5GB JSONL / 1,700 万输出 token，M3 Pro 冷索引 4 秒【官方宣称·README】）。关键约束转述：Claude Code 默认 `cleanupPeriodDays=30` 天清理历史【官方文档转述】——这是需求的真实来源（数据会消失）。但两个死因：① 仅 macOS（Apple Silicon），Windows 空位虽在；② 转录格式无 schema 稳定性承诺，上游每次改格式都是维护税；③ 官方 Agent HQ 正在把会话管理做成产品功能（见 VS Code 报告 §4）。

**N4 规则文件同步**：agentmeld 的调研本身有方法论价值——210 个同时携带 AGENTS.md 和 CLAUDE.md 的公开仓库中 **30.5% 故意写不同内容**，说明「盲目镜像」是错的，正确架构是共享基座+overlay。记忆侧 claude-mem（自动捕获工具输出→压缩为 500 token 观测→FTS5+向量检索回注）方向上已把「个人版记忆」做满。

**N5 运行时安全**：APERION Shield 的 v1.0 更新日志几乎是本场景的「终局描述」：安装前审计（--scan）+ 运行时每调用拦截（51 规则+自适应评分+身份门）+ OS 级沙箱（macOS Seatbelt）+ 工具目录 pin（防 rug pull）+ 结果扫描（防注入外传），**个人开发者永久免费**。安全类工具的个人付费空间被「免费=信任」逻辑锁死（安全软件收费反而降低可信度）。

**N6 回滚**：注意官方双覆盖——Cursor checkpoints + Claude Code /rewind 已内置。第三方（Agent Rewind）只能差异化到「MCP 外部连接器的可逆性」（Gmail/Slack 等 agent 不可逆动作的补偿器），这已超出个人开发者交付能力。

**N7 会话→评测**：四个同期项目（Redline/EvalOS/TreeTrace/evotrace）的定位微差：prompt 回放回归 / 失败→测试用例 / 安全纠错→确定性 eval / 会话→训练资产。这是链路里唯一「从验证税中回收资产」的正向叙事，与首轮主论点（瓶颈转向验证与消化）直接对齐——**方向对，但时点已过**：拥挤度正在指数上升。

**N8 用量监控**：ccusage 一个项目就终结了讨论：18 个 agent CLI 的本地日志统一解析 + LiteLLM 价格表成本估算 + 5 小时窗口 + statusline + 离线模式，18.8k★、当天还在推。Anthropic 官方口径：Claude Code 企业部署平均 **$13/开发者/活跃天、$150–250/开发者/月**【官方宣称】——需求真实且持续，但供给端已分层完成（内置 /usage → 本地 CLI → 菜单栏 → 网关预算），每一层都有免费货。

## 四、结构性结论（本轮方法论增量）

### 4.1 「开源海啸」模式：链路层显性痛点的填平周期

| 场景 | 痛点公开时点 | 5+ 免费实现齐备时点 | 填平周期 |
|---|---|---|---|
| N1 slopsquatting | 2025（USENIX 论文） | 2026-03 ~ 2026-08 | **< 12 个月** |
| N2 MCP 审计 | 2025（MCP 普及） | 2026-06 ~ 2026-10 | **< 12 个月** |
| N5 运行时安全 | 2025 | 2026-06（APERION v1.0） | **< 12 个月** |
| N7 会话→评测 | 2026 上半年 | 已 4 个同类 | **进行中，< 6 个月** |

**推论（可复用判据）**：一个 AI 链路痛点如果在博客/论文/社区被公开讨论，默认假设是 12 个月内供给端免费填平。个人开发者的立项判据不是「痛点真不真」，而是「**为什么开源没做这个位置**」——答不出结构原因（分发/信任/数据/合规），就不要进。

### 4.2 三轮合并后的幸存模式（唯一的两个）

| 幸存者 | 为什么开源没做 | 模式 |
|---|---|---|
| RAG 体检 GUI 化 | deepeval/ragas 是**给开发者的库**，不是给知识库用户的**结果交付**；GUI 不产 Star（model-warden 0★ 教训），开源激励结构天然缺位 | 库 → 结果交付 |
| 本地部署安全修复段 | 检测有 GitHub Action 生态兜底；**修复**要触碰用户系统配置（防火墙/端口/白名单），开源作者不愿承担指导用户改系统的责任 | 检测 → 修复 |

### 4.3 判据沉淀（写入方法论的候选）

1. **检测/审计类单点工具：默认判死。** CI 生态（GitHub Action）+ 安全社区免费文化双重挤压，窗口期 < 6 个月，且免费是安全工具的信任前提。
2. **价值在修复段，不在检测段。** 同一痛点，检测免费、修复（改变用户系统状态并对结果负责）可收费——首轮 $99/次人工审计样本（ollama-security）是同构证据。
3. **官方功能是最大竞品。** N6（回滚）、N8（/usage）、N3（Agent HQ 会话管理）都死于官方内置。立项前必查：「这个链路环节是否在 Cursor/Claude Code/VS Code 的 roadmap 上」。
4. **GUI 化不是自动机会。** model-warden（完整 GUI 管家，0★）vs ccusage（CLI，18.8k★）——免费档位上 GUI 不产生付费意愿，只产生维护成本。

## 附 B · 敏感度说明

本轮为场景扫描，无财务测算。关键敏感点：
- **claude-mem 口径冲突（86k vs 30.5k）**：不影响任何结论（N4 判死不依赖 Star 数），但提示「二手 Star 数据必须过 API」的既有纪律不可省。
- **N3 Windows GUI 空位**：若官方在未来两个版本内置会话历史检索（概率主观估计中高），窗口归零；该方向任何投入前须先确认官方 2027 roadmap。
- **「填平周期 < 12 个月」判据**：基于 4 个场景的样本归纳，样本量小；若开源生态节奏放缓（融资收缩），周期可能拉长至 18 个月，届时 N7 类场景仍有窗口——结论方向不变，时点判断有 ±6 个月摆动。
