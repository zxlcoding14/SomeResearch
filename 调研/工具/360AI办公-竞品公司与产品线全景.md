# 360AI办公 — 竞品公司与产品线全景

> 采集日期：2026-10-23 ｜ 数据标签：【实测】=财报/官方披露可直接核验；【官方宣称】=厂商自述未第三方核验；【二手·媒体】=第三方报道/研报转述；【未取得】=缺口
> 币种换算假设【假设】：USD/CNY = 7.1（下文仅对需要比较的金额换算，产品标价保留原币）

## TL;DR

- **360AI办公（三六零/北京奇虎科技，aiwork.360.cn）的定位是「AI办公工具集 + 会员订阅」**：200+办公权益、30万+模板、AI PPT / AI写作 / PDF全家桶 / AI图片 / AI音视频，PC与移动双端，底层接360智脑与DeepSeek-R1满血版【官方宣称】。
- 与它正面竞争的不是一家公司，而是**四类玩家**：① 国内大厂AI办公平台（金山办公、百度、阿里钉钉/千问、腾讯、字节飞书、科大讯飞）；② 垂直工具单品（扫描/PDF赛道：合合信息扫描全能王、Adobe；PPT赛道：Gamma、AiPPT、iSlide、稿定等）；③ 国际办公套件（Microsoft 365 Copilot、Google Workspace Gemini）；④ 通用AI助手跨界（ChatGPT、Claude、Notion AI 等）。
- **体量差距悬殊**：360AI办公应用宝下载量仅约3.3万（移动端）；对比WPS国内年度付费用户4825万、百度文库AI月活9700万+（官方宣称）、钉钉8亿累计用户。360在该赛道的真实份额目前找不到公开数据【未取得】。
- 竞争主线已从「功能对齐」升级为「生态对撞」（大河财立方表述）：AI Agent 成为新的办公入口之争，各家都在把工具集收口成单一Agent入口（库库AI、千问办公、WorkBuddy、豆包工作伙伴、灵犀）。

## 一、竞品判定口径

360AI办公同时具备三个特征：**PC客户端形态**、**多场景工具集（PPT/写作/PDF/图片/音视频）**、**个人会员订阅制**。据此判定竞品的三条轴：

| 对照轴 | 说明 | 对应竞品群 |
|---|---|---|
| 功能对位 | AI PPT、AI写作、AI文档分析、PDF工具、AI图片/视频 | 百度文库、WPS AI、讯飞智文、垂直PPT工具 |
| 商业模式对位 | 工具集会员打包订阅（360AI大会员模式） | WPS会员、百度文库会员、扫描全能王订阅 |
| 入口对位 | 谁在争夺「AI办公总入口」（Agent化） | 千问办公、WorkBuddy、库库AI、豆包工作伙伴、Copilot |

## 五、竞争格局要点（PM视角）

1. **360AI办公的真实位置：国内AI办公工具集赛道的「腰部玩家」，四面对敌。** 上有WPS（Office正主+4825万付费用户）和百度文库（18亿文档+9700万AI月活）压着，横有钉钉/飞书/企微抢企业入口，纵有扫描全能王这类单品在每个功能模块做到极致。
2. **它的相对优势**：360系流量（安全卫士/浏览器分发）+「AI大会员」打包定价对价格敏感用户友好+DeepSeek满血版接入作为卖点。但这些优势没有公开运营数据支撑【未取得】。
3. **行业结构性变化：工具集→Agent收口。** 百度（库库AI）、阿里（千问办公/悟空）、腾讯（WorkBuddy）、字节（豆包工作伙伴）、金山（灵犀）全部在把多SKU收口成单一Agent入口。360AI办公目前仍是「工具货架」形态，尚未看到同等力度的Agent化动作——这是产品形态层面的落后风险。
4. **扫描赛道的信号**：Microsoft Lens退市说明独立文档工具在被「系统内置+Agent」双重挤压；合合信息的应对是转型为Agent的原子能力供应商（接入千问办公连接器市场）。这个趋势对所有工具单品玩家（包括360的工具模块）同样适用。
5. **付费转化率是共同瓶颈**：钉钉付费组织转化率不足1%；各家都在从「会员订阅」转向「订阅+AI用量」（金山智点、百度按次API、微软Copilot席位计价）。360的纯会员包模式在Token成本压力下的可持续性存疑。
