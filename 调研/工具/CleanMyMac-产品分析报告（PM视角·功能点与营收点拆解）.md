# CleanMyMac（MacPaw）— 产品经理视角分析报告

> **分析对象**：CleanMyMac 5（MacPaw 旗舰产品，原名 CleanMyMac X）
> **最新版本**：5.5.7（2026-07-22）｜**系统要求**：macOS 11+，320 MB
> **分析视角**：产品经理 — 功能点梳理 / 主要营收点拆解 / 商业化结构 / 竞品与替代
> **数据截止**：2026-09-28｜**汇率**：USD/CNY = 6.7195（2026-09-28，open.er-api.com）；2024 年均价按 7.12 近似
> **数据性质**：公司财务数据来自英国 Companies House 审计账目（硬数据）；用户/使用量数据来自官方自述（标「宣称」）；口碑数据来自第三方平台（标「第三方」）；付费用户规模为本文**推算**（标「推算」）

## 〇、结论先行（TL;DR）

1. **营收点不在"清理"，在"清理之外的四件事"。** CleanMyMac 的定价被切成 Basic / Plus 两档：Basic（清理垃圾 / 加速 / 卸载更新应用 / 去重 / 健康监控）只是入口，**Plus 价格直接翻到 1.95 倍（中国区 ¥199 → ¥388）**，而 Plus 新增的全是 **Cloud Cleanup 云盘清理 + Space Lens 磁盘可视化 + 大文件与隐藏文件 + 恶意软件移除 + 隐私保护**。→ **能加价的从来不是"帮你省空间的功能"，而是"省空间 + 安全感"的组合。**

2. **CleanMyMac 一台产品撑起 MacPaw 整个公司。** 官方口径 CleanMyMac ≈ **80% 集团营收**，对应 FY2024（审计）**US$72.17M ≈ ¥4.85 亿**（按 2024 年均价 ¥5.14 亿）。集团 FY2024 总营收 US$90.21M（≈¥6.06 亿），Setapp 占 15%（≈US$13.5M），其他所有产品加起来只占 5%。

3. **计费结构是"订阅优先 + 买断兜底 + 三重折扣"的三明治。** 1 Mac 年付 US$39.95（$3.33/月）、2 Macs $63.95、5 Macs $127.95；一次性买断 US$119.95（折年化仅 $23.99）。折扣体系极其激进：**老版本升级折扣 + 竞品用户 40% off + 自家其他产品用户 30% off**——这意味着**标价与实际成交价之间存在系统性落差**，任何用标价算 ARPU 的估算都会高估收入。

4. **付费用户规模反推 ≈120–180 万，实收 ARPU ≈US$45–59/年。** 两条独立路径收敛到同一区间：① 按标价 $39.95 反推 = 181 万；② 按 Forbes Ukraine 披露的 2021 年 100 万月付费用户 × 官方近三年 7% 复合增速（1.07³）= 122.5 万，对应实收 ARPU $58.9。**两个数字互相印证 → CleanMyMac 的付费用户量级约在 120–180 万，而不是官方"3000 万用户"给人的印象。**

5. **最大风险是"单一 SKU + 品类被上下夹击"，而 MacPaw 的自救动作已经承认了这一点。** 上方：macOS 内置（存储管理 / 系统设置 / XProtect / 活动监视器）持续吃掉基础需求；下方：OnyX、AppCleaner、PearCleaner 免费，DaisyDisk US$11.99 买断（折年化 ¥16/年）。**同一时期 MacPaw 关停了三条扩张线（CleanMy PC 2025 停、Setapp Mobile 2026-02 关闭、CleanMyMac Business 2026-07-14 关停），把资源全部压向 AI 助手 Eney。**

## 二、全功能点枚举（按模块 × 工具）

计数口径：**模块级 8 个 / 可独立感知工具 25+ 个**（官方自述"6 大功能块 + 25+ 工具"）。下表把每个工具归入"是否 Basic 已含 / 需 Plus"。

| # | 模块 | 具体工具与能力 | 档位归属 | 用户价值类型 |
|---|---|---|---|---|
| M1 | **Smart Care（智能呵护）** | 一站式扫描：垃圾清理 + 恶意软件深扫 + 性能维护 + 重复文件 + 应用更新（5 个例行程序合并，tile 化界面） | Basic | 体验入口 |
| M2 | **Cleanup（清理）** | 系统垃圾（缓存 / 日志 / 用户日志 / 语言文件 / 通用二进制）、废纸篓、邮件附件、浏览器残留 | Basic | 省空间 |
| M3 | **Protection（保护）** | 恶意软件移除（**Moonlock Engine**）、隐私清理（浏览记录 / 最近项目 / 线上与线下痕迹）、应用权限管理、PUA（潜在不受欢迎应用）识别、扫描深度与速度档位（快速/均衡/深度）、扩展扫描范围（磁盘映像 / 压缩包 / USB / iCloud 文件） | **Plus** | 安全感 |
| M4 | **Performance（性能）** | 维护任务（释放可清除空间 / 刷新 DNS 缓存 / 精简 Time Machine 快照）、登录项管理、后台扩展管理；**MAS 版不含全部 Performance 工具** | Basic（部分需 Plus） | 速度感 |
| M5 | **Applications（应用）** | 彻底卸载（含残余、支持数据）、重置应用、应用更新、遗漏的 macOS 更新提醒 | Basic | 省空间 + 省心 |
| M6 | **My Clutter（我的杂物）** | 大文件与老旧文件、长期未打开的下载、**重复文件**、**相似图片** | Basic（大文件属 Plus 口径） | 省空间 |
| M7 | **Space Lens** | 磁盘空间可视化映射 → 探索扫描结果 → 复核并删除 | **Plus** | 可视化卖点 |
| M8 | **Cloud Cleanup（云清理）** | 连接 **iCloud Drive / Google Drive / OneDrive / Dropbox**，扫描云端冗余并删除、结果可视化、断开连接 | **Plus** | 云存储焦虑 |
| M9 | **Menu App（菜单栏监控）** | 健康仪表盘：CPU / 内存 / 磁盘 / 电池 / 网络实时监控、Mac 健康指数与建议、我的活动记录 | Basic | 感知价值（高） |
| M10 | **智能助手** | CleanMyMac Assistant：AI 驱动的对话式引导，基于内置知识库给出清理/维护建议 | Basic | 体验层（AI 落地最浅的一层） |
| M11 | **辅助能力** | VoiceOver / Reduce Motion 无障碍支持、扫描提醒设置 | Basic | 合规/体验 |

**功能点计数结论**：模块 8–11 个、可独立感知工具 25+ 个。**其中真正被 MacPaw 划进 Plus 付费档的只有 5 类能力（M3 保护 + M7 Space Lens + M8 云清理 + M6 大文件）——占比约 20%，但它们承担了相当于 Basic 档 1 倍的溢价。**

## 三、功能点四层分层（T1–T4）与商业可提取性

| 层 | 判据 | CleanMyMac 对应功能 | 占比（估） | 商业含义 |
|---|---|---|---|---|
| **T1 主干范式** | 删掉它就不是 CleanMyMac | Smart Care 一键扫描、系统垃圾清理、菜单栏健康监控、25 工具聚合的"一体化" | ~25% | 获客功能，**必须留在最低档** |
| **T2 场景能力** | 决定"能不能真用起来" | 卸载残余清理、重复文件/相似图片、大文件清理、应用更新、登录项管理、维护任务 | ~35% | 留存功能，与免费替代重合度最高 |
| **T3 界面细节** | 决定"顺不顺手" | Space Lens 可视化、tile 式交互、CleanMyMac Assistant 引导、健康指数、My Activity | ~15% | **口碑与加价来源（Plus 的一半溢价在这里）** |
| **T4 工程保障** | 用户看不见，删掉就崩 | **Moonlock Engine（自研恶意软件引擎 + 持续更新的特征库）**、Safety Database（防误删白名单）、Apple 公证、ISO 27001、全盘访问权限管理、云盘 OAuth 接入（4 家） | ~25% | **唯一有真实持续成本的层 → 唯一能正当收订阅的层** |

### 商业可提取性映射（本报告最有价值的一张判断）

| 可提取性 | 对应功能 | 判据 |
|---|---|---|
| **强（能撑订阅）** | Moonlock 引擎与威胁库更新、Cloud Cleanup（云盘 OAuth + 持续扫描）、Space Lens 的持续维护、跨设备授权 | 有**持续交付成本**：威胁库要每天更新、云 API 要维护、多设备要授权管理 |
| **弱（可做增强包）** | 重复文件 / 相似图片（算法有边际成本但无持续成本）、大文件扫描、应用更新（第三方更新源需维护） | 有边际成本、无持续成本 |
| **无（基础体验）** | 系统垃圾清理、废纸篓、DNS 缓存刷新、Time Machine 快照精简、登录项管理、菜单栏监控 | **纯本地、无成本、无理由重复收费**——macOS 内置或免费工具可完全覆盖 |

> **规律（与 PopDrop / czkawka 调研一致，本产品是第三次验证）**：**功能点的投入强度与商业可提取性呈负相关。** CleanMyMac 把最多的工程量（Moonlock 引擎、Safety Database、硬件兼容性）放在 T4，把最多的免费用户感知放在 T1/T2；**收入真正来自 T3 的可视化 + T4 的持续成本**，而 T1/T2 里最"像清理软件"的那部分，恰好是最不能收费的部分。

## 四、主要营收点拆解（核心章节）

### 4.1 定价阶梯（多口径实测）

| 口径 | 1 Mac | 2 Macs | 5 Macs | 一次性买断 | 月付 |
|---|---|---|---|---|---|
| **官网 US（USD，实测）** | **$39.95/年**（$3.33/月） | $63.95/年（$6.66/月，原 $79.90） | $127.95/年（$10.66/月，原 $199.75） | — | — |
| **官网 CN（CNY，实测）** | Basic **¥199/年**・Plus **¥388/年** | Basic ¥398/年 档存在 | 存在 5 台档 | **¥576（Basic）/ ¥919（Plus）** | ¥66/月 档存在 |
| 中国代销（麦软 mycleanmymac.com） | **¥208/年** | — | — | **¥566 永久版** | — |
| 第三方渠道记录（FileHorse / MacUpdate 用户） | $39.95/年 | $59.95/年 | $89.95/年 | **$89.95 或 $119.95**（记录冲突） | $9.95/月 档 |

**折年化人民币（spot 6.7195）**：1 Mac ¥268/年 → 2 Macs ¥430/年 → 5 Macs ¥860/年；**买断 $119.95 折年化仅 $23.99 ≈ ¥161/年**。

**三个必须点出的定价事实：**
- **买断比年付便宜 40%**（$119.95 买断 vs $39.95/年，2.4 年即回本）→ 买断档在结构上**是年付的对手盘，不是补充**。MacPaw 用"仅约 2.5 倍年费"的话术包装它，但理性用户算完一定选买断，代价是**永久封印续费收入**。
- **中国区是唯一跑通"双档分层"的市场**：Basic ¥199 / Plus ¥388（1.95×）。美国区官网只呈现"1/2/5 Macs"的**设备阶梯**，没有 Basic/Plus 的**功能阶梯**——**同一个产品在不同地区的付费墙位置不同**，中国区把付费墙设得更靠前（云+安全+可视化单独加价）。
- **月付是对冲口**：$9.95/月（≈$119.4/年）几乎等于买断价，属于典型"用月付价把年付衬托便宜"的锚点。

### 4.2 Basic vs Plus 的功能分界 = 付费墙的位置

| 分界 | Basic 已含（¥199/年） | Plus 才给（¥388/年） |
|---|---|---|
| 内容 | Smart Care 一键优化、清理 GB 级垃圾、性能加速、卸载与更新应用、删除重复与相似文件、监控 Mac 健康 | **云存储清理（Cloud Cleanup）**、**Space Lens 磁盘可视化**、**查找大文件与隐藏文件**、**移除恶意软件威胁**、**保护 Mac 隐私** |
| 功能数量占比 | ~80% 的工具 | ~20% 的能力 |
| 定价 | 基准 | **1.95×** |

**判定：这是"功能墙"，不是"用量墙"，也不是"交付墙"。**
- 好消息：墙设在"能力边界"上，**免费试用 7 天是全功能**，用户体验到完整价值后再决定买不买 → 口碑中性偏好。
- 坏消息：被墙住的 5 项里，**"移除恶意软件"和"隐私保护"本质上是安全品类的入口**。把安全当加价包卖，会让用户形成"付费才安全"的负面联想（同类负面案例：CCleaner 的历史争议），并且**在专业安全评测里被降级为"不是完整杀毒"**（多个第三方评测明确指出其未通过 EICAR 等测试文件）。

### 4.3 折扣体系（ARPU 的系统性折损源）

| 折扣类型 | 力度 | 触发条件 |
|---|---|---|
| 老版本升级折扣 | 未公开具体数字 | 从 CleanMyMac X 升级（需 macOS 11+） |
| **竞品用户折扣** | **40% off** | 只要能证明在用任何其他 Mac 清理器或杀毒软件 |
| 自家产品用户折扣 | **30% off** | 已拥有任意其他 MacPaw 产品（Setapp / Gemini / ClearVPN 等） |
| 首年优惠券 | 仅第一年生效 | 促销期官网发放 |
| 学生折扣（Setapp 侧） | 约 5 折 | 学生身份验证 |

**PM 读数**：40% off 的竞品置换券说明**获客成本已经内化到价格里**；而"折扣仅适用于第一年"意味着**续费按原价**，第二年续订率会经历一次价格冲击——这是消费级工具订阅最典型的暗坑，也是 MacPaw 需要"AI 新增价值"来对冲的续费风险。

### 4.4 付费用户规模与 ARPU 反推（推算，非官方）

| 推算路径 | 算法 | 结果 |
|---|---|---|
| A. 按标价反推 | CleanMyMac 营收 US$72.17M ÷ $39.95 | **180.7 万付费用户** |
| B. 按历史付费用户增长 | 2021 年 100 万月付费用户（Forbes Ukraine）× 官方近三年均增速 7%³ | **122.5 万付费用户** |
| C. B 路径反算实收 ARPU | $72.17M ÷ 122.5 万 | **US$58.9/年** |
| D. 折中口径 | 取实收 ARPU $45–59、对应 120–180 万付费用户 | **实收 ARPU ≈¥300–396/年** |

**关键推论**：实收 ARPU（$45–59）**明显高于标价 $39.95**，唯一合理解释是**多设备套餐与买断档在收入结构中占比较高**（2 Macs $63.95、5 Macs $127.95、买断 $119.95 均为高客单）。→ **CleanMyMac 的钱不是"人均一份年费"收来的，是"一台设备之外的设备"收来的。**

## 八、改进建议（P0 / P1 / P2）

| 优先级 | 建议 | 理由与预期收益 |
|---|---|---|
| **P0** | **把"安全"从 Plus 档拆出来，给最低档一个真实的安全底线**（如：恶意软件扫描与移除进入 Basic，实时防护/深度扫描留 Plus） | 目前"付费才安全"是信任负债。安全是 Mac 用户最愿意付钱但也最容易被免费方案（XProtect）替代的项——**把它做成准入而非加价，能显著降低试用转付费的心理阻力** |
| **P0** | **给订阅加"新增价值"，禁止靠"功能阉割"续费** | 现有新增价值只有 Cloud Cleanup（4 家云盘）+ Space Lens + Moonlock 特征库。**必须再挖一条有真实持续成本的付费理由**（候选：本地 AI 语义去重 / 跨设备存储治理 / 云盘去重与版本回收 / 备份快照管理）——参照 Raycast 的"订阅买体验层、credits 消化模型成本"模型 |
| **P1** | **重新设计买断档与年付档的关系** | 现状买断 2.4 年回本，理性用户必选买断，续费收入被永久封印。建议：买断版限定当前大版本（现状已如此）**并明确版本升级需重新购买**，把"持续威胁库更新"作为订阅独占——**让订阅卖"持续服务"，而不是卖"继续用"** |
| **P1** | **修 Application Manager 的 Leftovers 误判问题，并在删除前提供"这些文件正在被使用"的显式提示** | 这是当前公开评价里最尖锐、风险最高的一条负面原话（*"点错一下我就全没了"*）。误删→信任崩塌→差评→获客成本上升，是消费级工具最致命的链条 |
| **P1** | **应用更新加白名单/黑名单** | 用户明确反馈"自动勾选全部更新可能把应用升到新的付费版本"，这是可开发、可传播的口碑修复项 |
| **P2** | **中国区把 Basic/Plus 双档结构全球化** | 中国区是唯一把"云 + 安全 + 可视化"单独加价的市场（¥199 → ¥388）。美国区仅按设备数分档，**同一批功能在美区被免费送掉**，损失了溢价空间 |
| **P2** | **免费试用去掉绑卡要求 + 给出"7 天全功能"的明确无摩擦入口** | 直接对标 Nektony 系产品的差评点；试用摩擦是转化漏斗的第一道漏损 |
| **P2** | **把"51K 台 Mac/天"这类弱指标换成人均清理量与留存率** | 现有效据口径彼此不匹配（见附录缺口），对外不可验证，对内无法指导决策 |

### 数据缺口（诚实标注）

1. **CleanMyMac 单独的收入从未被正式披露**——80% 是创始人口径，无审计拆分，实际区间可能在 75%–80%。
2. **"约 51,000 台 Mac/天"与付费用户量级不匹配**：若真有 120 万+ 付费用户，日活维护量不应只有 5.1 万（除非该数字只统计"新装机首扫"或某个子集）。**此指标不可作为用户规模依据。**
3. **买断价冲突**：$89.95（FileHorse）vs $119.95（官网自述与 MacUpdate 用户记录），未取得官方定价历史以确认是涨价还是口径差异。
4. **Basic / Plus 分档是否全球上线未确认**：仅中国区页面呈现，US 版本多次抓取均未出现该分档。
5. **续订率 / 流失率未披露**：MacPaw 未公开 CleanMyMac 的订阅续费率（对照：万兴科技自述订阅续约率 >60%），这是评估其收入质量最关键的缺失指标。
6. **中国区实际销量与麦保（深圳）科技有限公司的经营数据未取得**（该子公司股东已于 2024-11-01 由 MacPaw HK Limited 变更为 MacPaw Family Ltd）。
