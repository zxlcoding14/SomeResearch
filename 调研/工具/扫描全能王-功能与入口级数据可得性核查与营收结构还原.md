# 扫描全能王（CamScanner）功能 / 入口级数据可得性核查 与 营收结构还原

> 核查日期：2026-09-29
> 核查范围：A 股年报与半年报、港股招股书（H0255）、机构调研纪要、券商研报、三方数据平台（Sensor Tower / data.ai）、公司官网与官方 FAQ、应用商店内购清单
> 核查目的：回答「扫描全能王各入口 / 各功能下的使用量（输入状况）是否有数据？营收比例分布是否有数据？」

---

## 〇、结论先行（TL;DR）

1. **功能级、入口级的收入与使用量分布：公开渠道为零，一条都没有。** 不存在"去水印贡献 X% 收入""相机入口贡献 Y% 流量"这类数据，任何声称有的来源都是编造或推算。
2. **公司不是"没统计"，而是"主动不披露"，且披露颗粒度在系统性收窄——三年收窄了两次、维度从 8 条降到 4 条。** 2024 年报机构调研中公司亲口承认了这次口径变更。
3. **唯一现成的、可持续跟踪的"结构分布"是「付费订单结构比率」**（月费 / 半年费 / 年费 / 其他），来自港股招股书。这是目前能拿到的、最接近"营收比例分布"的公开数据。
4. **把公司口径与券商口径对齐后，可以把扫描全能王拆到第二层：会员收入 vs 广告收入。** 我做了交叉校验，误差为 0。**这是本次核查最有价值的产出。**
5. **替代路径存在**：用「付费墙倍数差 + 功能独占性 + 版本更新顺序 + 评论关键词聚类」四个代理指标，可以反推出一张定性的功能价值权重表——但它给的是"排序"，不是"百分比"，**报告里必须标注为推断而非披露。**

| 颗粒度 | 层级内容 | 是否有公开数据 | 数据来源 | 覆盖期 |
|---|---|---|---|---|
| **L0** | 公司整体营收 / 净利 / 毛利率 | ✅ 完整、经审计 | A 股年报 | 2018–2026H1 |
| **L1** | 业务线（智能文字识别 / 商业大数据 × C 端 / B 端） | ✅ 完整 | A 股年报 | 2018–2026H1 |
| **L2** | 单品（扫描全能王 / 名片全能王 / 启信宝 / TextIn / 启信慧眼） | ⚠️ 仅"扫描全能王"单品，且只在港股招股书披露 | 港股招股书 | 2022–2025Q3 |
| **L3** | 收入类型（VIP 会员 / 单次付费 / 互联网广告 / 手机厂商技术授权） | ⚠️ 仅 2018–2024，**2024 年起被并入合并** | 招股书 + 机构调研 | 2018–2024 |
| **L4** | 付费结构（月费 / 半年费 / 年费 / 其他订单占比、对应续购率、ARPPU） | ✅ 有，且逐期更新 | 港股招股书 | 2022–2025Q3 |

## 二、披露颗粒度的三次收窄（本次核查的核心发现）

对比不同年份的披露文件，可以看到一条清晰的信息收窄轨迹：

| 时期 | 披露维度数 | 具体维度 | 变化 |
|---|---|---|---|
| **2018–2022**（科创板招股书时代） | **8 条** | 智能文字识别 B 端 / C 端-扫描全能王 / C 端-名片全能王 ｜ 商业大数据 B 端 / C 端-启信宝 ｜ **互联网广告推广** ｜ **手机厂商技术授权** ｜ 其他业务 | 基线：业务线 + 变现方式双维度 |
| **2023–2024**（A 股上市后） | **6 条** | 上表中"互联网广告推广"并入"智能文字识别 C 端"，"手机厂商技术授权"并入"其他" | 变现方式维度消失 |
| **2024 年报起** | **4 条** | 智能文字识别 C 端 / 智能文字识别 B 端 ｜ 商业大数据 C 端 / 商业大数据 B 端（+ 其他） | 变成"赛道 × 客户类型"矩阵 |
| **2026 中报** | **4 条** | 同上，C 端与 B 端进一步合并为赛道口径 | 继续合并 |

### 公司对这次收窄的原话（2024 年 4 月，32 家机构调研 · 问题 13）

> 问：公司年报中的按产品的收入披露口径发生了变化，互联网广告收入拆分到了产品当中，这样做的考量，未来的产品商业化方式是否会发生变化？
>
> 答：广告收入均为 C 端产品产生，**为更清楚体现收入与产品的相关性，保证产品收入分类与公司未来发展方向更加一致，更加符合商业逻辑**，并且广告收入并非主要盈利来源，公司 2024 年主营业务收入分类口径将 APP 互联网广告收入合并至 APP 收入中进行披露，将收入占比较低的手机厂商技术授权合并至其他。

**PM 视角的解读**：这是典型的"会计口径服务于叙事"操作。合并后有两个好处：① 外部无法再看出"广告变现能力在增强还是衰减"；② "广告并入 APP 收入"会让单品收入看起来更完整、更"产品驱动"，而掩盖"付费转化吃力、只能靠广告补量"这一风险信号。**披露口径的每一次收窄，都值得当作一个负面信号来读。**

## 三、营收比例分布能还原到多细？（三层还原表）

这是对"营收比例分布"最有实际价值的部分。

### 3.1 第一层：公司层收入结构（2025 全年，已审计）

| 收入类型 | 金额 | 占比 | 毛利率 |
|---|---|---|---|
| 智能文字识别：C 端产品（扫描全能王 + 名片全能王） | ¥14.86 亿 | 82.12% | 89.78% |
| 商业大数据：B 端产品及服务（启信慧眼等） | ¥1.70 亿 | 9.41% | 68.72% |
| 智能文字识别：B 端产品及服务（TextIn 等） | ¥0.87 亿 | 4.81% | 71.53% |
| 商业大数据：C 端产品（启信宝） | ¥0.58 亿 | 3.18% | 86.14% |
| 其他 + 其他业务 | ¥0.09 亿 | 0.48% | — |
| **合计** | **¥18.10 亿** | **100%** | **86.70%** |

### 3.2 第二层：单品层（仅扫描全能王，港股招股书口径）

| 年份 | 扫描全能王收入 | 占公司总营收 |
|---|---|---|
| 2022 | ¥7.15 亿 | 72.3% |
| 2023 | ¥9.05 亿 | 76.2% |
| 2024 | ¥11.12 亿 | 77.3% |
| 2025Q1–Q3 | ¥10.51 亿 | **80.6%** |
| 2025 全年（推算） | **≈ ¥14.5–14.6 亿** | **≈ 80.1%–80.8%** |

> 推算方法：2025Q1–Q3 营收 ¥13.03 亿、扫描全能王 ¥10.51 亿；全年营收 ¥18.0964 亿 → Q4 营收 ¥5.07 亿，按 Q4 同比例（约 81%）得 Q4 扫描全能王 ≈ ¥4.11 亿，合计 ≈ ¥14.62 亿。另用「智能文字识别 C 端 ¥14.86 亿 − 名片全能王（占比约 1.7–2.0%，≈¥0.31–0.36 亿）」反推得 ≈ ¥14.50–14.55 亿。两法交叉一致。

### 3.3 第三层：扫描全能王内部——会员 vs 广告（⚠️ 口径歧义破解）

这里有一个**此前无人指出、但会直接误导判断的口径陷阱**：

- **招股书口径**的"扫描全能王"＝ **会员收入 + 分配给它的互联网广告收入**
- **A 股年报 / 券商口径**的"扫描全能王"＝ **仅会员收入**

**校验过程（误差为 0）：**

| 年份 | 招股书口径(A) | 券商口径·会员(B) | 广告(C) | 校验 A = B + C |
|---|---|---|---|---|
| 2022 | ¥7.15 亿 | ¥6.33 亿（招股书 64.03% × 9.88 亿） | ¥0.82 亿（8.32% × 9.88 亿） | 6.33 + 0.82 = **7.15 ✓** |
| 2023 | ¥9.05 亿 | ¥8.09 亿（国金证券） | ¥0.96 亿（8.1%） | 8.09 + 0.96 = **9.05 ✓** |
| 2024 | ¥11.12 亿 | ¥9.82 亿（中银证券，68.31%） | ¥1.30 亿（9.0%，yoy +36%） | 9.82 + 1.30 = **11.12 ✓** |

**三年全部严丝合缝。** 由此得到 2025 全年扫描全能王的内部结构估算：

| 扫描全能王内部拆分 | 2024（实测） | 2025E |
|---|---|---|
| 会员订阅（VIP） | ¥9.82 亿（88.3%） | ≈ ¥12.8 亿（≈88%） |
| 互联网广告 | ¥1.30 亿（11.7%） | ≈ ¥1.7 亿（≈12%） |
| **合计** | **¥11.12 亿** | **≈ ¥14.5 亿** |

> **⚠️ 口径警告**：2024 年起广告已被并入 APP 收入，因此**现在看到的"扫描全能王 ¥14.5 亿"里已含约 12% 的广告收入**，不再近似等于"订阅收入"。任何拿"扫描全能王收入"直接除以付费用户数算 ARPPU 的做法，从 2024 年起都会系统性偏高超 10%。

### 3.4 与「单次付费」相关的补充口径

- 招股书口径：**2021–2023 年 VIP 会员收费收入占 C 端收入比重均超过 80%**，其余主要是付费报告等单次付费产品。
- 应用商店证据（iOS，2026-03 数据）：扫描全能王 9 个内购项中，**7 个是订阅（周 / 月 / 年），仅 1 个为一次性付费（One-page Fax $0.99）**，均价 $23.10，区间 $0.99–$59.99。
- ⇒ **结论：单次付费是长尾，占比 <20%；订阅（含"付费版"独立 App）是绝对主力。** "各个功能的营收占比"在结构上就不会按功能拆——因为钱是按"会员身份"收的，不是按"功能调用"收的。

### 四个关键解读

1. **订单结构发生了一次剧烈迁移：月费 58.9% → 33.1%（−25.8pct），半年费 1.1% → 31.2%（+30.1pct）。** 半年费从"可忽略"变成"与月费、年费三分天下"。
2. **这是被动的政策工程，不是主动的产品创新。** 公司在调研中明确说明：为响应连续续费标准化政策、降低用户单次支付金额，把部分年费用户的扣费节奏从"一次性扣费"改为"年度内多次扣费"——**这个动作直接伤到了 2024 年现金流**（当年经营性现金流净额增速与归母净利增速出现较大背离）。
3. **ARPPU 在降（185.7 → 178.0 元），付费用户在涨（5.3M → 9.3M）。** 典型的"薄利多销式增长"：牺牲客单价换付费人数和留存。这也解释了为什么付费用户增速（+19.68% / 2026H1）能持续跑赢 MAU 增速（+9.94%）。
4. **"其他购买订单比率"从 1.4% 升到 6.6%（4.7 倍）**，是所有档位中相对增幅最大的——**说明单次付费/轻付费产品（付费报告、单次传真、单次证件照等）正在成为新的探路品**。这是观察"功能级变现"的唯一一条间接线索。

## 五、为什么"功能级 / 入口级"数据拿不到：四条硬原因

| # | 原因 | 说明 |
|---|---|---|
| 1 | **归因不可能** | 一份文档的典型链路是「相机 → 图像增强 → OCR → 转 Word → 签名 → 云存储 → 分享」。收入在链路的哪一环产生？无法切分。这是结构性障碍，不是统计疏漏。 |
| 2 | **销售单元是"会员身份"不是"功能"** | 用户买的是一次性打包的 VIP，不是"去水印 ×1 次 + OCR ×1000 次"。除了少数单次付费 SKU，功能层根本没有独立的收入流。 |
| 3 | **核心经营机密** | 功能级使用分布 = 产品路线图。一旦公开，竞品可以直接照抄功能投放优先级。 |
| 4 | **监管未强制、公司在主动收窄** | 会计准则只要求到"主营业务分类"层；公司在 2023、2024 两次主动合并维度（见第二节）。 |

**⇒ 结论：不要指望任何公开渠道能拿到功能级数据。** 遇到声称有的第三方报告，先检查其口径说明。

## 六、替代方案：用四个代理指标反推功能价值权重

既然拿不到直接的，就用间接的。以下四个代理指标可以拼出一张**定性**权重表（标注为推断，不可当披露数据引用）。

### 代理 A：付费墙倍数差 = 功能价值权重（最硬的反向证据）

免费版限额 vs 会员版限额的**倍数差**，直接反映公司对每个功能的"定价自信度"。倍数越大 ⇒ 该功能越被当作转化引擎。

| 功能 | 免费版额度 | 付费版 / 会员额度 | 倍数 | 墙体类型 |
|---|---|---|---|---|
| 高级提取文字（云端精准 OCR） | 体验 3 次 | 1,000 次/月 | **≈333×** | 配额墙 |
| 在线 OCR | 10 次/月 | 1,000 次/月 | **100×** | 配额墙 |
| 拍题识别 | 3 次 | 不限次数 | **∞** | 配额墙 |
| PDF 转 Excel | 1 次/月 | 不限次数 | **∞** | 配额墙 |
| PDF 转 Word / PPT | 0（仅限时体验） | 会员可用 | **独占** | **独占墙** |
| 书籍模式 | 10 页/天 | 不限次数 | **∞** | 配额墙 |
| 证件模式 | 0 | 会员可用 | **独占** | **独占墙** |
| 拼图模式 | 0 | 会员可用 | **独占** | **独占墙** |
| 电子签名 | 0 | 会员可用 | **独占** | **独占墙** |
| 免广告 + 去水印 | 0 | 会员可用 | **独占** | **独占墙** |
| 防盗用水印 | 0 | 会员可用 | **独占** | **独占墙** |
| 证件照 | 0 | 10 次/月 | **独占** | **独占墙** |
| PDF 加密 / 长图 | 0 | 会员可用 | **独占** | **独占墙** |
| 照片修复 | 10 次/天 | 1,000 次/月 | **≈3.3×** | 配额墙 |
| 云空间 | 1 GB | 10 GB（企业 20 GB/人） | **10×** | 容量墙 |
| 回收站 | 7 天 | 30 天 | **4.3×** | 时长墙 |
| 文件夹数量 | 8 个 | 不限 | **∞** | 配额墙 |

**读法（两条经验法则，可直接复用）：**

- **"独占墙"功能才是定价骨架**（转 Word / 转 PPT / 证件模式 / 拼图 / 电子签名 / 去水印 / 防盗水印 / 加密 / 长图）——免费版完全没有，用户只有买或不买。
- **"配额墙"功能是诱饵**（OCR 100×、拍题 ∞、转 Excel ∞）——免费给一点、用一次就卡住，目的是制造"卡顿感"把用户推向上付费页。**倍数越大的功能，越不是靠它赚钱，而是靠它促转化。**

### 代理 B：权益清单的排列顺序 = 公司的注意力排序

官网"20+ 特权功能"的呈现顺序（免费版 vs 会员版逐条对照）本身就是产品经理的优先级表达。可观察到：**云空间（1GB→10GB）排在第一位**，而**免广告去水印排在第 7 位**。但结合投诉结构可反推：**排在后面的"去水印"才是实际转化触发器，排在前面的"云空间"是价值锚点。**

### 代理 C：版本更新日志 = 资源投入顺序

版本迭代的功能上线顺序，等价于公司内部的功能级资源分配序列（2026 年可观察到的重点：智能高清滤镜、大尺寸扫描、AI 跨模态鉴伪、翻页自动拍）。这是**唯一能反映"公司自己认为哪个功能重要"的公开信号**。

### 代理 D：应用商店评论关键词聚类（可行，本次未做）

抓取 App Store / Google Play 评论并按功能关键词聚类，可以近似得到"用户提及频次"（≈使用频次代理）与"抱怨频次"（≈付费触发点代理）两个分布。
**⚠️ 但它给的是"声量"，不是"营收"，且存在严重样本偏差（抱怨者更愿意写评论）。** 若要使用，必须与代理 A 交叉验证。

## 七、入口地图：可枚举，但无流量占比

从产品结构、官方操作手册与商店描述可完整枚举出输入通道，**但没有任何公开数据给出各入口的流量或收入占比**。

| # | 入口类别 | 具体入口 | 说明 |
|---|---|---|---|
| 1 | **主入口** | 首页中央「＋」/ 相机按钮 | 被多家教程称为"进入扫描流程的唯一入口" |
| 2 | **本地导入** | 相册导入 / PDF 导入 / 文件导入 | 免拍照路径 |
| 3 | **子扫描模式**（同一相机入口下的分流） | 文档 / 证件模式 / 书籍模式 / 拍题 / 名片 / 白板 / PPT / 表格 / 电子证据 | 识别引擎按模式分化（普通 / PPT / 表格 / 书籍 / 拍题） |
| 4 | **跨端入口** | PC 端 / Web 端上传（Web 端 PDF 转 Word 免费） | 提 ARPU 的薄弱环节 |
| 5 | **外部导入** | 微信 / QQ / 钉钉 / 邮件 / 云盘（Dropbox、Google Drive、OneDrive、百度网盘） | 双向：既导入也导出 |
| 6 | **协作入口** | 团队文件夹共享 / 邀请协作 / 评论 | 企业版主要差异点 |
| 7 | **输出侧（营收点但不属"输入"）** | 导出 PDF / JPG / Word / Excel / TXT、无线打印、全球传真（30+ 国家地区）、加密分享链接、长图分享 | 传真为单次付费 SKU |

**PM 视角的关键观察**：入口是 7 类，但**"营收点"和"入口"并不对齐**——最赚钱的收费动作（导出无压缩 / 转 Word / 去水印 / 传真）全在**输出侧**，而入口侧（相机、导入）**100% 免费、且永远免费**。这从结构上解释了为什么"按入口拆收入"这件事在商业上无意义：**入口是获客成本中心，不是收入中心。**

## 九、数据缺口清单（明确标注"无公开数据"）

以下问题**在公开渠道无解**，任何报告若给出具体百分比，均应视为不可信：

1. 各功能（去水印 / OCR / 云存储 / 证件 / 拼图 / 签名 / 拍题 / 鉴伪…）的收入占比
2. 各入口（相机 / 相册 / PC / 微信导入…）的流量占比或转化率
3. 各功能的使用频次占比（只有极少数孤立绝对值）
4. 免费的"卡顿点"（配额耗尽的节点）的具体触发分布
5. 广告收入在扫描全能王内部按广告位 / 按页面位置的拆分
6. 各订阅档位（周 / 月 / 季 / 半年 / 年）的**金额**占比（只有**笔数**占比）
7. 境内 vs 境外用户的**功能偏好**差异
8. 教育 / 商务 / 法律 / 医疗等场景的**收入贡献**占比（只有场景定性描述）
