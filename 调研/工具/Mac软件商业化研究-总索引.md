## 二、跨报告复用的四套分析框架

这四套框架是本条研究线最可迁移的部分，已在后续报告中被反复验证：

### 框架 1：价值锚点分析法（竞品矩阵报告提出）
竞品卖的不是功能，是**五个不同的焦虑**。定价位置几乎完全由锚点决定：

| 锚点 | 用户真实诉求 | 极致代表 | 商业可提取性 |
|---|---|---|---|
| V1 认知卸载 | "我该删什么？" | CleanMyMac Smart Care / 腾讯柠檬清理 | 中 → 可支撑订阅 |
| V2 可视化 | "空间去哪了？" | DaisyDisk | 中，**撑不起订阅** |
| V3 安全感 | "删了会不会坏 / 有没有毒" | MacKeeper / Intego / MacBooster | **强 → 高价订阅** |
| V4 可量化省空间 | "给我一个 GB 数字" | 几乎所有产品的宣传页 | **弱 → 只能换免费用户** |
| V5 掌控感 / 身份 | "我要自己决定" | OnyX / Pearcleaner | 弱 → 只能 donation |

### 框架 2：功能点四层分层（Czkawka + CleanMyMac 报告提出）
按"删掉它，产品定义会不会变"分层，用来判断**该功能能不能收费**：

| 层 | 含义 | 商业含义 |
|---|---|---|
| T1 主干范式 | 定义产品的那个按钮 | 获客，必须留在最低档 |
| T2 场景能力 | 具体场景的完成度 | 留存，与免费替代重合度最高 |
| T3 界面细节 | 交互与呈现 | **口碑 + 加价来源** |
| T4 工程保障 | 安全库 / 公证 / OAuth / 引擎 | **唯一有持续成本 → 唯一能正当收订阅** |

> 规律已验证三次：**投入强度与商业可提取性负相关。** 工程量最重的 T4 用户看不见，最像"清理软件"的 T1/T2 最不能收费。

### 框架 3：ARPU 断层（两报告独立实测得出）
把一切计费方式统一折算为**年化单用户人民币**（买断按 5 年摊销），再与功能覆盖度对照：

- Mac 清理赛道：**¥0 → ¥268**，功能重合度 **85%**
- 重复文件查找赛道：**¥0 → ¥1,290**，Czkawka 功能覆盖度 ≥ Duplicate Cleaner Pro
- **结论：价格与功能数量无关，与「整合度 × 品牌信任 × 人群净值」强相关。**

### 框架 4：下载速度归一化法（Czkawka 报告提出）
GitHub 的 `download_count` 是**自发布起累计值**，直接比大小会得出与事实相反的结论。必须**除以在架天数**再看趋势。同一手法也适用于任何"只有累计口径"的分发渠道。

## 五、数据口径与诚实缺口

### 证据强度分级
- **硬证据**：上市公司年报 / Companies House 注册与审计文件 / 平台 API 实测（GitHub、Flathub、Chocolatey、crates.io、官方定价页）
- **软证据**：第三方估算库（差异可达 4 倍，仅作区间参考）、官方宣传页的"用户数/下载量"宣称
- **缺口**：完全未披露的私营公司收入

### 关键缺口（未解决，需后续补）
1. **Clario Tech（MacKeeper）与 Dr.Buho（BuhoCleaner）收入完全未披露** —— 本赛道最大两个空白。
2. **CleanMyMac 单独收入从未审计披露**，80% 为创始人口径。
3. **续订率 / 流失率完全缺失** —— 订阅型产品最关键指标，全部无公开数据。
4. CleanMyMac Basic/Plus 双档是否全球上线未确认（**确认的是中国区官方页**呈现此结构）。
5. CleanMyMac 买断价 $89.95（FileHorse）vs $119.95（官网）冲突未解。
6. 官网"约 51K 台 Mac/天"与 120 万+ 付费用户量级不匹配，**不可作规模依据**。
7. DigitalVolcano 走 Micro 实体豁免，**无营收申报义务**，仅能读到现金与净资产。
8. 名科国际年报未拆分 MacBooster 单品收入。

## 六、三条可迁移结论（跨赛道）

1. **"一次性需求 × 无持续交付成本"下，收第二次钱在结构上不可能。** 与「克隆赛道」被 OEM 白送 + OS 内置封锁同构。
2. **"被操作系统内置 = 品类死亡判决"已验证五次**（虚拟桌面、磁盘清理、备份克隆、重复文件查找、应用卸载）。
3. **投入强度与商业可提取性负相关。** 用户看不见的 T4 是唯一能做订阅的地方；用户最看得见的 T1/T2 最不能收费。
4. **本地化定制是被严重低估的护城河。** 腾讯柠檬清理在中文区打败 CleanMyMac 靠的不是价格，是"它能清微信，CleanMyMac 不能"。
5. **开发者磁盘（Xcode / Docker / node_modules）是 ARPU 最高的清洗对象，而至今没有一个产品把它做成独立产品线。**
