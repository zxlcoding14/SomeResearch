## 一、软件定位

- **一站式多格式**：常见格式（PDF、Office、CAD、Markdown、图片等）直接在软件内打开，无需为不同格式安装/切换不同程序
- **本地优先（Local First）**：资料库完全存本机，不强制登录、不上传云端，隐私可控
- **打开快**：文档在本地，预览即点即开，无云端加载等待，不反复拉起外部应用
- **轻量免费**：当前版本完全免费，安装包小巧，开箱即用

## 二、核心功能特性

### 1. 多格式内置预览
- PDF（基于 Poppler 渲染，1.0.1 重构后支持选择文字复制）
- Office：Word（.docx）、Excel（.xlsx）、PowerPoint（.pptx）
- CAD 图纸：.dwg / .dxf / shp
- Markdown（.md / .markdown）与纯文本（.txt）
- 图片：PNG、JPG/JPEG、GIF、BMP、WebP、PSD、SVG 等
- 视频：.mp4 / .avi / .mkv / .mov / .webm / .wmv / .flv / .m4v / .mpg / .mpeg 等
- 代码：C/C++、Python、JavaScript 等数十种代码文件
- HTML：.html/.htm 通过 WebView2 预览（1.0.1）

### 2. 多面板界面
- 左侧：文件夹 / 标签 / 收藏 / 智能文件夹（1.0.2）/ 最近文档
- 中间：即时预览
- 右侧：笔记面板及网页面板
- 下方：文件列表面板
- 另有：大纲面板、搜索结果、剪贴板面板（1.0.4）

### 3. 大纲导航
- 对 Markdown、JSON、XML 及数十种代码文件自动解析层级结构
- 生成可点击大纲树，长文档快速跳转定位

### 4. 标签与收藏
- 标签做跨文件夹多维分类
- 常用文档/文件夹加入收藏，可手动排序
- 星级评分系统（1.0.2 全新重构）：图形星星、悬停预览、点击/双击编辑、按 1-5 星筛选

### 5. 两种导入方式
- **复制进资料库**：文件副本入库，集中管理
- **链接到原文件**：只记录原路径不占空间，原文件改动实时反映
- 1.0.4 新增**文件夹链接**：外部文件夹直接链接到软件内部，实时同步

### 6. 元数据提取
- 导入时自动读取图片、PDF、Office、电子书等文件的标题等元信息

### 7. 全文搜索
- 支持普通文本类文档全文检索（其他格式后续研发）
- 搜索框按标题即时筛选，结果列表显示匹配数量

### 8. 笔记功能（NoteDock）
- 内置 Markdown 笔记编辑器，随手记录、自动保存
- 可给文档打标签 + 记备忘笔记，笔记与文档关联不再孤立
- 1.0.1：支持在软件内新建笔记文档
- 1.0.3：支持插入/粘贴本地图片

### 9. 文件列表面板
- 表格视图：列含名称、类型、大小、修改时间、标签，点表头排序
- 支持网格、自由等多种视图，1.0.1 后图标视图大/特大图标支持图片预览
- 大资料库流畅浏览

## 三、各版本新增功能

### 1.0.1
- HTML 预览（WebView2）
- 图片图标预览（图标视图/自由视图大图标模式）
- URL 链接导入：剪贴板 URL 用 Ctrl+V 导入，软件内直接浏览网页
- 文件拖拽到外部软件打开
- 文件导出：按文件夹结构导出 / 整库导出
- 新建笔记文档
- PDF 预览窗重构，支持选择文字复制

### 1.0.2
- 星级评分系统（重构）：悬停预览、点击/双击编辑、星级筛选
- 智能文件夹系统：集成到左侧面板、文档数量实时更新、一键清除筛选
- 快速打开对话框（重写）：全局热键系统级呼出、双列布局（Tab 切换、Ctrl+Enter 进目录）、点击外部自动隐藏、右键菜单（Shift+F10）
- 视频格式预览（.mp4/.avi/.mkv/.mov/.webm/.wmv/.flv/.m4v/.mpg/.mpeg）
- PSD 文件预览

### 1.0.3
- 截图工具：常见截图编辑功能，方便截取文档
- OCR 功能：纯本地方案，集成 OCR 引擎，识别正确率 90%+
- 笔记支持插入/粘贴本地图片

### 1.0.4
- 文件夹链接：外部文件夹链接进软件，实时同步
- 剪贴板面板：监控剪切板、内容分类、批量导入、实时悬浮预览
- RSS 阅读器：添加外部 RSS 源，软件内直接阅读

## 四、其他面板/细节

- **最近文档面板**：按时间自动归集最近打开/导入的文档
- **网页面板**：软件内嵌常用网页或在线文档（如豆包网页版可当免费 AI 入口）
- **智能文件夹**：左侧面板，数量实时更新，一键清除筛选
